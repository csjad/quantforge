# D-003｜数据源选型（主辅排序与频控基准）

- 状态：已接受｜日期：2026-11-13｜决策人：角色1（A1 裁决），A2/A8 会签
- 来源：工程正文 S02 技术正文表9，项目内闭环（冲突 C-022/C-023/C-025）

## 背景与约束
- 本系统存在四类数据来源：本地文件、在线积分源、在线免费源、手工导出。选型核心问题：**私有化交付的立身之本是离线可跑**——卖家交付包必须能让买家断网跑通第一个回测。
- 合规红线：仅个人研究、不二次分发、不绕过访问限制；频控参数外置配置，不硬编码。

## 备选方案与打分（表9，工程正文原文数值；依据句为本轮补充）
| 维度（权重） | 方案甲 本地文件优先 | 方案乙 Tushare 为主 | 方案丙 AkShare 为主 |
|---|---|---|---|
| 可离线（0.30） | 完全可离线 | 不可 | 不可 |
| 数据完整度（0.25） | 取决于用户导入 | 高，字段规范 | 中，偶有缺列 |
| 稳定性（0.20） | 高 | 中，受积分与频控 | 中，接口变动频繁 |
| 成本（0.15） | 零 | 按积分付费 | 免费 |
| 接入工作量（0.10） | 低 | 中 | 高，需兼容多版本 |
| 加权总分 | **4.4** | 3.7 | 3.2 |

依据句：权重来源=产品取向排序（可离线0.30为首，因离线交付是立身之本；数据完整度0.25次之，直接决定回测可信度；稳定性0.20、成本0.15、接入工作量0.10）。方案甲在"可离线"维度满分且零成本，乙在数据完整度与字段规范上占优，丙免费但接口变动频繁、接入工作量最高。

## 决策（D-003）
**选定方案甲为主、乙为增量补充**：
- **主通道＝本地文件（离线数据包）**：交付随包，断网可跑，S19/S44 离线包只需实现一个"本地文件源"，引擎零改动。
- **增量补充＝Tushare**：在线增量拉取（积分型，每分钟≤200次）。
- **免费源＝AkShare**：备选在线源（每分钟≤60次），接口变动频繁，适配层负责兼容。
- **可选备用＝Baostock**（C-025扩展项，工程正文未列，不改变主辅排序）。

## 频控基准（随 D-003 冻结）
- Tushare：每分钟≤200次，令牌桶容量200、填充速率200/分；退避一、二、四秒；连续三次失败即中止本次任务并记录断点。
- AkShare/Baostock：每分钟≤60次，令牌桶容量60。
- 深度展开补充：退避三段式加抖动（首次2秒、第三次8秒、第五次32秒+暂停该源10分钟，抖动=基数30%）；禁止多进程并发、伪造请求头、切换出口地址。

## 后果与影响
- S02 适配层四方法契约（列标的/取日线区间/取分钟线区间/取复权因子事件）为唯一接入面，新增数据源只加实现不改引擎。
- 频控参数全部外置配置；观测指标（调用成功率/限频率/隔离率/补采收敛率）每批次落库。
