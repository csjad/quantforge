# D-004｜撮合与滑点模型终选

- 状态：已接受｜日期：2026-11-13｜决策人：角色1（A1 裁决），A3/A6 会签
- 来源：工程正文 S03 成本模型口径（默认固定每边千分之一），项目内展开三方案对比

## 背景与约束
- 滑点直接决定回测收益的可信度：滑点设为0或过小，年化收益凭空多出十几个百分点（S00 诚实优先取向）。
- 约束：成交价统一按开盘价成交（C-026）；滑点方向对买方加、对卖方减；报告首页强制打印模型与参数。

## 备选方案与打分
| 维度（权重） | 方案甲 固定滑点 | 方案乙 波动比例滑点 | 方案丙 盘口分层滑点 |
|---|---|---|---|
| 实现复杂度（0.25） | 极低，一个常数 | 中，需当日振幅率 | 高，需分档逻辑 |
| 保守性（0.30） | 高，恒定保守 | 中，波动大时偏保守、平稳时偏乐观 | 中，分档近似 |
| 数据依赖（0.20） | 无 | 当日开高低收 | 当日成交量/成交额 |
| 可复现性（0.15） | 强，报告可精确复算 | 强 | 中，分档边界敏感 |
| 切换成本（0.10） | 默认 | 可选 | 可选 |
| 加权总分 | **4.3** | 3.4 | 3.2 |

依据句：权重来源=产品取向（保守性权重最高0.30，防收益虚高是第一要务；实现与可复现次之，因为要交付可复算的报告；数据依赖与切换成本权重低）。方案甲恒定保守、零数据依赖、报告可精确复算；方案乙在平稳行情下偏乐观（滑点偏小），与"诚实优先"取向有张力；方案丙在日线无真实盘口的条件下只能以成交量近似，分档边界敏感、复现性弱。

## 决策（D-004）
**默认方案甲（固定每边1‰）；方案乙、丙作为可切换模型。**
- 方案乙（波动比例）：滑点率 = k ×（当日振幅/前收），k默认0.25，封顶2‰。
- 方案丙（盘口分层）：按委托股数占当日成交量比例分三档（<1%、1~5%、>5%），滑点率0.5‰/1‰/2‰——日线无真实盘口，以成交量近似盘口深度。
- 切换方式：回测任务参数 `slippage_model = fixed | volatility | depth`；报告首页强制打印所用模型与参数（可复现优先于高性能）。

## 后果与影响
- S05 策略接口：下单参数仅声明目标数量与方向，滑点模型由任务级配置统一施加（策略不感知）。
- S09 绩效：成本项在报告中逐项打印，四类成本允许一键关闭做对照（关闭仅用于教学对照，正式结论必须含全部成本）。
