# D-005｜参数遍历寻优策略选型

- 状态：已接受｜日期：2026-11-13｜决策人：角色1（A1 裁决），A3/A4 会签
- 来源：工程正文 S06 技术正文表16（工程正文内部编号 D-004；项目编号因 D-004 已用于滑点模型，顺延为 D-005，见冲突单 C-028）

## 背景与约束
- 在有限算力下把参数空间跑完，并且**不把自己骗了**——寻优的陷阱不是算得慢，而是把过拟合的最优当策略有效。
- 硬约束：并发=物理核数−2、分钟线并发减半（内存交换陷阱）；遍历结果必须附带全部指标与过拟合标记（S06-02）。

## 备选方案与打分（表16，工程正文原文数值；依据句为本轮补充）
| 维度（权重） | 网格遍历 | 随机搜索 | 贝叶斯优化 |
|---|---|---|---|
| 覆盖完整性（0.30） | 完整 | 概率覆盖 | 不保证 |
| 参数维度容忍（0.25） | 差，维度爆炸 | 好 | 好 |
| 实现复杂度（0.20） | 低 | 低 | 高 |
| 可解释性（0.15） | 高 | 中 | 低 |
| 结果稳定性（0.10） | 高 | 中 | 依赖先验 |
| 加权总分 | 3.8 | **4.1** | 3.2 |

依据句：权重来源=寻优任务的核心诉求（覆盖完整性0.30为首，决定空间是否被充分采样；维度容忍0.25次之，决定高维空间可行性；实现与可解释性各占两成与一成五，决定交付与教学成本；稳定性一成）。网格在低维（≤2参数）覆盖完整且可解释，但维度爆炸使其在3参数以上不可行；随机搜索在同等预算下期望覆盖更好；贝叶斯依赖先验且不可解释，但高维效率最高。

## 决策（D-005）
**V1 采用随机搜索为主、网格遍历为对照。**
- 理由：三参数以上时网格组合数呈指数增长，同等预算下随机搜索的期望覆盖更好；
- 网格保留用于**两参数以内的穷举**，便于教学演示与结果可视化（地形格子图即用网格结果绘制）；
- **贝叶斯优化留到 V3**，与模型模块一并实现。

## 配套机制（随决策冻结）
- **搜索空间三道裁剪**：步长裁剪（连续参数按步长离散）、边界裁剪（按经济含义剔除无意义区间）、**相关性裁剪**（按经济等价性降维——双均线在"快慢比+基准窗口"维度遍历，1000组压至约200组）。
- **任务分片续跑**：一组参数一任务，标识=策略标识+参数哈希+数据快照号；执行中任务重启回退待执行；已完成按结果文件+校验和双重确认；**禁止把执行中直接标已完成**。
- **性能口径（表17）**：日线单标的100组约5分钟（P-04≤8分钟锚点）；池内500标的必须**抽样加复核**（50只遍历→前20组→全池复核，复核骤降为负则扩抽样到150只重做）。
