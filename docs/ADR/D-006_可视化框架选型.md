# D-006｜可视化框架选型（渲染方案）

- 状态：已接受｜日期：2026-11-13｜决策人：角色1（A1 裁决），A6/A8 会签
- 来源：工程正文 S10 技术正文（三方案对比后选定），项目内立档

## 背景与约束
- 交付物以**PDF报告为核心**（S09 报告可复现设计），静态图是刚需；
- 离线交付包必须能断网运行；面板交互为附加体验；
- 数据不外泄：交互图不得上传云端。

## 备选方案与打分
| 维度（权重） | 方案甲 Matplotlib 静态渲染 | 方案乙 Plotly 实时图表 | 方案丙 ECharts 前端方案 |
|---|---|---|---|
| PDF嵌入稳定（0.30） | 强，PNG可稳定嵌入 | 弱，HTML无法嵌入 | 弱 |
| 离线运行（0.25） | 强 | 强 | 弱（需本地打包依赖） |
| 交互性（0.20） | 无 | 强 | 强 |
| 数据不外泄（0.15） | 强（本地文件） | 强（仅面板、不上传） | 中（前端渲染本地可行但依赖打包） |
| 维护成本（0.10） | 低 | 低 | 中（双运行时） |
| 加权总分 | **4.4** | 3.6 | 2.6 |

依据句：权重来源=产品交付形态（PDF报告为核心，PDF嵌入与离线运行权重最高0.55合计；交互性0.20为附加体验；数据不外泄0.15为合规底线）。方案甲在PDF嵌入与离线两项满分；方案乙交互强但PDF嵌入弱，定位为面板附加体验；方案丙纯前端，PDF嵌入为零、离线需打包，且与Plotly角色重叠，淘汰。

## 决策（D-006）
**选定：服务端静态渲染为主（Matplotlib 输出 PNG）、面板实时为辅（Plotly 输出 HTML）。**
- 静态PNG：报告PDF嵌入、离线交付包、图表可导出PNG（DoD）；
- Plotly HTML：**仅在面板中提供，不上传云端，避免数据外泄**；
- ECharts：不采用（淘汰理由见上表）。

## 配套机制（随决策冻结）
- 渲染独立进程执行 + 队列（最多2并行）+ 缓存（任务标识+视图版本）；
- 降采样由平台实现并固定（每像素列取该列内最小与最大两个点）；
- 图按任务标识+图表类型命名，30天清理（保留PDF）；
- 面板默认只监听本机地址。
