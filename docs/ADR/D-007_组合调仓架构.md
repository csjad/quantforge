# D-007｜组合调仓架构

- 状态：已接受｜日期：2026-11-13｜决策人：角色1（A1 裁决），A3/A5 会签
- 来源：工程正文 S21 技术正文+C-035 消解方案，项目内立档

## 背景与约束
- V2 目标：单标的回测扩展为组合回测（S20）。V1 账户模型为单账户单标的串行，组合要求并行决策，资金分配时机冲突（C-035）。
- 约束：V1 策略接口不改（S20 核心决策）；组合级资金安全是第一要务（资金重复占用=回测失真）。

## 决策（D-007）
**组合调仓三重保障：两阶段决策 + 先卖后买 + 资金守恒检查。**

1. **两阶段决策**（承接 C-035）：先收集全部标的信号→统一分配资金→批量提交委托；**信号集中间状态落盘**，中断可断点续跑（A3 条件）；
2. **先卖后买硬规则**：卖出按超配程度降序、买入按低配程度降序，同一标的当日不得既卖又买；卖出所得支付买入，杜绝"目标权重合理但资金不足"死锁；
3. **资金守恒检查**：全部委托提交前，卖出预计回款+可用现金必须覆盖买入预计所需资金，不足按缺口比例缩减买单（向下取整到百股）；**不允许透支**。

## 配套机制（随决策冻结）
- **再平衡触发**：默认只开阈值触发（偏离>5个百分点）+最小间隔5个交易日；三类触发不可全开（防过度交易，成本吃掉收益）；
- **权重二次约束**：单标的30%/行业集中度/流动性三道→归一→复检，迭代上限3次，不收敛报错"约束不可满足"并给出具体冲突项；
- **跌停降级**：卖出因跌停无法成交→买入按实际回款等比例缩减（可为零）→记录"卖出未成交导致调仓未完成"，偏离保留到下次窗口；
- **组合绩效扩展**：组合年化波动、标的贡献度、**调仓成本占比**（频繁调仓高费率可吞噬全部超额收益，定量：月度调仓+千分之二双边+年换手4.8倍≈年成本0.96%）；
- **执行偏离度**：每次调仓记录实际vs目标权重绝对值之和，>10%在报告标注；
- **熔断联动**：组合模式熔断同样生效，熔断期间禁止调仓买入（A5 条件）。
