# D-009｜W1 图表与 HTML 报告选型（零依赖内嵌 SVG，不取代 D-006）

- 编号：D-009｜日期：2026-11-14｜状态：生效
- 关联：D-006（Matplotlib 主 + Plotly 辅，可视化框架）、D-008（W1 嵌入式形态）、S09-01 §5（报告页序）、S10（可视化面板）

## 背景

D-006 冻结的可视化框架为 Matplotlib（部署形态）。W1 嵌入式形态（D-008）的硬约束是**零第三方依赖**（离线五件事在任何机器解压即跑）——引入 Matplotlib（及其二进制依赖链）直接违背该约束，且离线包体积预算（S44：主包 200MB）会被依赖拖大。

## 决策

1. **W1 报告图表 = 纯 stdlib 手写内嵌 SVG**（权益折线 / 回撤水下面积 / 月度收益柱状，`charts.py`）；
2. **报告双形态**：Markdown（机读/版本管理）+ **HTML 单文件**（内嵌 CSS+SVG，无 JS、无外链、可离线双击打开，`report_html.py`）；
3. **页序沿用 S09-01 §5 冻结口径**：首页九项配置 + 自检量在前，收益在后——首屏决定可信度反应。

## 理由

- SVG 为文本资源：生成零依赖、体积小（单图数 KB）、任何浏览器可渲染，符合离线包"断网 30 分钟跑首份报告"的验收路径（S44）；
- 无 JS 的单文件 HTML 没有"打开时联网加载 CDN 字体/库"的隐患（S46 三处隐式在线依赖检查的落地）；
- 与 D-008 同一逻辑：部署形态恢复 D-006 的 Matplotlib/面板，接口以"图表数据序列"为界（charts 输入=权益曲线三元组）。

## 后果与复核触发

- SVG 仅覆盖三张基础图；**K线图、热力图、交互联动不在 W1 范围**——S10 六类图的其余类型留部署形态，需求不被本决策取消；
- 图表美学上限有限；若 V2+ 需要"给人看的精致图"，在部署形态切换 D-006 并保留本模块作降级路径；
- 被取代时标注取代关系（本记录只增不改）。
