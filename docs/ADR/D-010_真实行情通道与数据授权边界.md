# D-010｜真实行情通道与数据授权边界（可选采集层，引擎仍只读 CSV）

- 编号：D-010｜日期：2026-11-14｜状态：生效
- 关联：D-003（本地文件主/AkShare免费源60次每分/Tushare增量）、D-008（W1 嵌入式零依赖）、C-039（离线包不含在线拉取）、S19/X-14（商品合规）

## 背景

W1 引擎只消费 CSV（D-008）。用户提出"接真实行情数据替代合成样例"。直接在引擎里接在线源会破坏两条冻结结论：①D-008 零依赖（akshare 及其依赖链体积大）②C-039（离线包不含在线拉取）。

## 决策

1. **真实行情 = 可选采集层**（`realdata.py`，依赖 akshare，单独安装）：在线拉取 → **落地为 CSV**（`data/kline_real/`，标的+年分区，与 D-002 分区键一致）→ 引擎照常只读 CSV。**引擎代码零改动**，物理截断与可复现性不受影响；
2. **样例池与真实池物理隔离**：`data/kline/`（合成，可分发）与 `data/kline_real/`（真实，不可分发）两个目录；回测经 `--data-dir` 选择；
3. **授权边界强制随目录**：真实数据目录强制写《数据来源与授权说明》——版权归东方财富（经 akshare），**仅限个人研究，不得二次分发、不得进入任何售卖包/离线交付包**（附录D、S19 合规口径）；monetize 打包清单不含该目录；
4. **频控**：免费源 60 次/分（D-003），拉取间隔 ≥1.1 秒；
5. akshare 未安装时给出明确安装指引，**不静默降级**（SEC-07 同源纪律：联网成败两态不同结果比装不上更糟）。

## 后果与复核触发

- Tushare 增量源（D-003）留扩展位：接口同为"拉取→CSV"，换源只改 `fetch_one`；
- 真实数据的除权口径固定为**前复权 qfq**（报告"复权模式"项如实标注）；
- 若未来把真实数据接入离线包=触碰数据版权红线，**否决**（S51 长期不变三条之外的第四条硬边界，登记于本 ADR）；
- 被取代时标注取代关系（本记录只增不改）。
