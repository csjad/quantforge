# D-012｜本地 Web 控制台形态（新默认入口，tkinter 保留为经典版）

- 编号：D-012｜日期：2026-11-15｜状态：生效
- 关联：D-008（嵌入式零依赖）、D-009（SVG 图表）、S55（动态端口先例）、用户前端红线（等大灰盒平铺=稀烂）

## 背景

tkinter 图形版（W1）功能完整但形态受限于原生控件——默认灰底等宽控件平铺，触发用户两条已验证的审美红线（大灰盒平铺=稀烂）。用户要求换形态。

## 决策

1. **新默认入口 = 本地 Web 控制台**（`webconsole.py`）：stdlib `http.server`，**127.0.0.1 动态端口**，启动自动开浏览器；零第三方依赖（D-008 不变）；
2. **界面按前端红线配方**：巨型锚点数字（最近回测四项指标，44px/28px 字号带）、去框化（无卡片堆叠，hairline+留白）、A股红涨绿跌；
3. **tkinter 保留为经典版**（`qf_gui.py`），两入口并存；
4. 端口纪律：动态端口=非服务形态，不进 S00 六端口清单（S55 同例先例）；
5. 启动器：`启动QuantForge界面.bat` 改指 Web 控制台（Anaconda 解释器链不变）。

## 后果与复核触发

- 页面无外部资源（无 CDN/字体），离线可用（S46 三处隐式在线依赖检查通过）；
- 浏览器形态使图表/排版迭代成本趋近于零（改 HTML 即生效），未来 V10~V12 的面板需求在此演进；
- 被取代时标注取代关系（本记录只增不改）。
