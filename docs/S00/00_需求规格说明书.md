## 1. 产品定位与边界

### 1.1 一句话定位
单机私有化的A股多策略量化平台：历史数据批量回测 + 参数寻优 + 风控熔断 + 模拟撮合信号输出 + 自动报告，全部本地运行，支持纯离线。

### 1.2 明确做什么（V1 范围）
| 范围 | 内容 |
|---|---|
| 市场 | A股（沪主板/深主板/创业板/科创板）；默认剔除北交所 |
| 数据 | 日线（全A约5,130只默认池）+ 分钟线（1/5/15/60min，默认池≤200只） |
| 回测 | 单标的与标的池批量回测，区间默认 2018-01-01 至最新落库交易日 |
| 撮合 | A股规则模拟撮合（T+1、涨跌停、停牌、费率、滑点） |
| 输出 | 绩效指标15项、图表、PDF报告、寻优榜单 |
| 信号 | 模拟盘信号经鉴权 Webhook 出网；回测模式禁止出网 |

### 1.3 明确不做什么（边界，防范围蔓延）
| 不做项 | 理由 | 何时可能做 |
|---|---|---|
| 实盘下单对接券商 | 合规与资金安全；V1 只输出信号不执行 | V9 后评估，默认永不自动下单 |
| 云端多用户 SaaS | 定位单机私有化 | V9 多租户 |
| 期货/港美股/加密货币 | 超出A股范围 | 不在 V1~V12 计划 |
| 分布式集群 | 单机优先，买家机器资源有限 | V8 |
| 移动端 App | 面板本地 Web 已够用 | V11 轻量查看面板 |

## 2. 运行模式定义（S00 DoD 强制项）

### 2.1 双模式表
| 维度 | 纯本地离线模式 | 在线数据源模式 |
|---|---|---|
| 数据来源 | 本地离线数据包（随商品分发）/ 通达信导入（V2候选）/ 已落库缓存 | AkShare(东财源)/Baostock/Tushare Pro 三通道，见《02_外部数据源对接清单》 |
| 网络 | 断言零出网请求（X-02） | 限流出网：≤3 请求/秒，重试退避 1/2/4/8 秒×4 次 |
| 功能可用性 | 回测/寻优/报告/面板全功能 | 全功能 + 增量同步 |
| 校验 | 数据包导入时全量12条校验规则 | 每根K线入库前同样12条校验 |
| 适用 | 无外网环境、售卖演示 | 日常自用 |

### 2.2 回测与模拟撮合边界表（S00 DoD 强制项）
| 维度 | 回测模式 | 模拟撮合模式 |
|---|---|---|
| 数据 | 历史批量K线重放 | 收盘后/定时增量拉取当根K线 |
| 时钟 | 事件驱动逐bar推进（引擎内部时钟） | 自然时间 + 每日收盘结算（15:30 后跑当日） |
| 信号出网 | 强制禁止（X-02，引擎内网络调用即抛异常并终止任务） | 允许：经 API Key 鉴权 Webhook 推送 |
| 费率/滑点配置 | profile=backtest | profile=paper（两套配置互不读取） |
| 撮合代码路径 | 与模拟共用同一撮合器（保证 R-008 一致性） | 同左 |
| 账户存储 | 回测任务独立结果库（按任务ID分区） | 模拟账户独立库，与回测互不读写 |

### 5.1 绩效指标清单（S09 实现口径；12项为验收基线，C-018对齐工程正文）
验收基线12项：总收益率、年化收益率（=（1+总收益率）^(243/交易日数)-1）、最大回撤（min(1-净值/历史峰值)）、卡玛比率（年化收益/最大回撤）、夏普比率（年化=日均值×√243/日标准差，无风险利率默认0）、索提诺比率（下行波动）、胜率、盈亏比（平均盈利/平均亏损）、最大连续盈利次数、最大连续亏损次数、交易次数、平均持仓周期（bar数）。
扩展实现项（保留实现、不计入验收）：平均盈利、平均亏损、持仓周期分布（分5档：≤5/6-10/11-20/21-60/>60 bar）。
