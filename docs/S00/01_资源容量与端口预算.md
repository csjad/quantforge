## 2. 存储容量预估（公式完整展开）

### 2.1 基础口径
- A股总数：约 5,400 只（2026-11口径）；默认池 **500 只**（C-012对齐工程正文），全市场日线可分批查询，分钟线限池。
- 年交易日：243 天（2021~2025 年均值 242.6 取整）；20年口径按5000交易日计。
- 每日bar数：Day=1；60min=4；30min=8；15min=16；5min=48；1min=240（4小时连续竞价，C-014新增30min；周线由日线聚合，逐笔/tick不支持）。

### 2.2 行数推导表
| 数据集 | 公式 | 行数 |
|---|---|---|
| 全市场日线20年 | 5000标的×5000交易日 | 25,000,000 = 2,500万行 |
| 池内500只×5年日线 | 500×243×5 | 607,500 ≈ 60.8万行 |
| 池内500只×5年5min | 500×48×243×5 | ≈ 2,920万行 |
| 池内500只×5年1min | 500×240×243×5 | ≈ 1.46亿行 |
| 全市场1min×1年（不入库，仅说明） | 5400×240×243 | ≈ 3.17亿行 |

### 2.3 单行体积与总量推导
- 单根K线体积口径：日期4字节、开高低收各4字节、量与额各8字节、主键4字节共44字节，计入对齐与页开销按 **96字节/根** 计（工程正文口径，S01实测校准）。
| 数据集 | 原始体积 | 含索引（约1倍） | 结论 |
|---|---|---|---|
| 全市场日线20年 | 2500万根×96B≈**2.4GB** | ≈**4.8GB** | 日线设为主力周期的主要依据，全市场可全量 |
| 池内500只×5年1min | 1.46亿根×96B≈**14.4GB** | ≈**29GB** | 分钟线限池500只五年的硬依据 |
| 池内500只×5年5min | 2,920万根×96B≈**2.8GB** | ≈5.6GB | 可接受 |
- **结论（作为S01输入约束）**：日线全市场20年可全量落库；分钟线只存池内500只五年，扩至1000只约58GB，须扩容磁盘或缩短年限，二者不可兼得（假设A-03）。

### 2.4 非行情数据体量
回测结果：每任务约**0.5MB**（资金曲线落文件+指标摘要），按年均1,000任务≈**0.5GB/年**（归档兜底）。报告：每份1~3MB。日志：每日**200MB**、保留14天≈**2.8GB**。备份：按两倍计约**70GB**。磁盘推荐≥256GB、建议512GB，留三成余量。

### 4.1 并发内存叠加验算（铁律8，C-010口径）
- 单任务内存上限：日线≤1.5GB、分钟线一年≤4GB（工程正文锚点）。
- 场景1（日线并发）：常驻0.8GB + (核数-4)×1.5GB。4核机器并发0（核数-4=0，仅单任务）：0.8+1.5=**2.3GB ≤ 16GB档** ✅；8核机器并发4：0.8+6.0=**6.8GB ≤ 32GB档** ✅；12核机器并发8：0.8+12.0=**12.8GB ≤ 64GB档** ✅。
- 场景2（分钟线任务）：单任务峰值≤4GB，8核机器并发2（减半）：0.8+8.0=**8.8GB ≤ 32GB档** ✅（分钟线建议在推荐档及以上运行）。
- 准入控制：内存使用率≥85%告警、≥95%拒绝新任务入队；超出由调度器按水位降级，不硬杀运行中任务。
