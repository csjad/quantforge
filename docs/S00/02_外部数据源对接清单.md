## 4. 降级与告警（C-022 修正，对齐工程正文）
- **切换开关**：配置文件 data.source=local|tushare|akshare|auto，切换数据源不改动回测引擎任何代码（S02 DoD）。
- **降级顺序**：在线两源互为备用（Tushare↔AkShare，按当前配置的主源失败自动切换），仍失败则转离线包提示；降级与失败必须记录**缺失标的清单**（A2评审条件：不得静默跳过，否则标的池静默缩水——缩水后的结果表面正常，是最难发现的一类失真）。
- **失败告警**：连续3次同步失败→"警告"；连续10次→"严重"并暂停该源（退避三段式：首次失败2秒、第三次8秒、第五次32秒并暂停该源10分钟；抖动幅度取基数30%，防多任务同步退避形成周期性冲击）。
- **IP封禁防护**：令牌桶（积分型200次/分、免费型60次/分）+ 指数退避 + 禁止绕过（多进程并发、伪造请求头、切换出口地址一律禁止）。
- **限频处置**：限频率长期高于10%时**下调速率**而不是加大重试——限频是对方的保护机制，硬顶只会让账号进黑名单。
- **观测指标**：调用成功率、限频率、隔离率、补采收敛率，每批次落库，7天窗口滚动展示。
