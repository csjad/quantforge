## 1. 五级校验管道（串联，每条K线入库前全级通过）

| 级 | 校验 | 内容 | 不通过处置 |
|---|---|---|---|
| 第一级 格式校验 | 字段齐全与类型正确 | 字段名与 S01 表结构一致、类型正确、代码后缀归一化 | 隔离 |
| 第二级 逻辑校验 | 执行 S01 清洗六规则（即 V-01~V-04 类，高低价关系、量额非负、唯一性、时间戳递增） | 见表10 | 隔离 |
| 第三级 连续校验 | 交易日缺口检测 | 缺失**超过3个连续交易日**则标记并要求补拉 | 登记缺口清单 |
| 第四级 交叉校验 | 抽样与第二数据源比对收盘价 | 偏差超过**千分之一**则告警；抽样比例**默认1%、可配置**（A3评审条件，避免全量比对拖慢导入） | 告警+人工确认 |
| 第五级 入库 | 通过者写 bars_raw 并触发复权计算 | 白名单校验（C-001）在此级强制执行 | 拒绝写入并告警 |

## 2. 十二条校验规则（表10）

| 编号 | 规则 | 判定阈值 | 处置 |
|---|---|---|---|
| V-01 | 最高价不低于开盘与收盘 | 严格 | 隔离 |
| V-02 | 最低价不高于开盘与收盘 | 严格 | 隔离 |
| V-03 | 高价不低于低价 | 严格 | 隔离 |
| V-04 | 成交量与成交额非负 | 严格 | 隔离 |
| V-05 | 同一标的同一日期唯一 | 严格 | 保留首条并登记 |
| V-06 | 时间戳严格递增 | 严格 | 隔离 |
| V-07 | 单日涨跌幅不超板块上限 | 主板一成、创业与科创两成、ST半成 | 告警并人工确认 |
| V-08 | 相邻两日价格跳变不超五成 | 超阈值 | 标记疑似除权 |
| V-09 | 停牌日成交量应为零 | 非零即异常 | 标记待核 |
| V-10 | 复权因子单调可逆 | 反算原始价偏差不超千分之一 | 隔离该标的 |
| V-11 | 缺口检测 | 连续三个交易日以上缺失 | 登记缺口清单 |
| V-12 | 价格精度与最小变动单位一致 | 分位对齐 | 四舍五入并记录修正笔数 |

### 2.1 V-07 与 V-08：防"看起来正常的错误"
数据源偶尔会把**未复权价与复权价混在一起返回**：混入后的曲线仍然连续、仍然满足高低价关系，但除权日会出现一个不可能的跳空。这种错误无法靠单条记录判定，只能靠相邻关系识别。因此 **V-08 的作用不是拒绝数据，而是把可疑点推到人工确认队列**——直接隔离会丢掉真实行情，直接接受会污染收益，两者都会让回测出现一段无法解释的走势。

## 3. 隔离区与重放

- **隔离表**：被隔离的记录不丢弃，写入隔离表并附**来源批次号、规则编号、原始行内容**。
- **三个重放入口**：
  1. 修正规则后全批重放；
  2. 单条人工修正后重放；
  3. 数据源变更后重拉整批。
- **隔离量收敛判断**：重放前先判断隔离量是否收敛——**某批次隔离率超过5%，视为数据源结构已变，直接阻断该源并转人工，不再逐条修补**。阈值定在5%的依据：正常脏数据率通常在千分之一量级，超过5%已不可能是偶发错误。

## 4. 缺口补采（三类缺口，三种处置）

| 缺口类型 | 定义 | 处置 |
|---|---|---|
| 整日缺失 | 某标的某交易日完全无记录 | 补采两次；仍失败则登记，并在回测中**把该日视为不可交易** |
| 区间缺失 | 某标的连续多日无记录（常见于长期停牌） | **按停牌处理，不补采**，只在元信息标记停牌区间 |
| 字段缺失 | 记录存在但成交额为零或复权因子为空 | 用同源另一接口补齐；仍缺则该字段参与计算时置空并降级 |

**核心原则：不把不可交易的日子补成可交易的日子。** 曾有一种做法是线性插值补价，结果是回测在那段时间里凭空做出几笔成交，收益曲线平滑得像被修过图。

## 5. 一次脏数据的实际处置（深入推导）

场景：某源在除权日返回了复权价，导致相邻两日价格跳变60%。
处置流程：
1. V-08 检出→标记疑似除权→推入待确认队列；
2. **先查复权因子表，再下结论**：
   - 因子在该日发生变化 → 判定"未复权数据混入" → **整批退回重拉**；
   - 因子无变化 → 判定数据源错误 → **隔离该标的该区间**。

关键：直接隔离会丢掉真实行情，直接接受会污染收益。先查因子再下结论，两者都不会让回测出现一段无法解释的走势。

## 6. 观测指标与告警

| 指标 | 定义 | 用途 |
|---|---|---|
| 调用成功率 | 成功次数÷总次数 | 源健康度 |
| 限频率 | 被拒次数占比 | 长期>10%→**下调速率**（不是加大重试） |
| 隔离率 | 隔离行数占比 | 批次>5%→阻断该源转人工 |
| 补采收敛率 | 两次补采后仍失败的比例 | 补采策略有效性 |

- 每批次落库，7天窗口滚动展示（S13 监控接入）。
- 告警联动：V-07/V-08 类"告警并人工确认"规则推待确认队列；隔离率>5%、连续失败10次等走 S02-01 §6 告警分级。
