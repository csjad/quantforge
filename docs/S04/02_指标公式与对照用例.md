# S04-02｜指标公式与对照用例（每指标≥3组）

- 文档编号：S04-02｜版本：v1.0｜日期：2026-11-13｜主责：角色4（A4），A3/A7 会签
- 口径基准：工程正文 S04 表13 + 深度展开递推初值；对齐主流行情软件默认口径
- 用例规范：每指标至少三组——①教科书级数值（已知输入→预期输出）；②边界输入（窗口首根、全同值、含空值）；③随机输入性质检查（单调性/对称性/量纲）

---

## 1. 均线族

### 1.1 MA 简单均线（含当日）
- **公式**：MA(N,t) = (C(t−N+1)+…+C(t))/N
- **口径**：窗口含当日；第1~N−1根输出空值；**缺失日中断窗口并标记缺口，不跳过计数**。
- **对照用例**：
  - TC-IND-001 教科书：序列[10,11,12,13,14]，N=3 → 第3根=11、第4根=12、第5根=13
  - TC-IND-002 边界：序列前2根 → 输出空值（窗口未满，不得填充首值）；含单日缺口序列 → 缺口日均线无值，后续窗口按真实交易日计算（前向填充陷阱用例，必须进回归集）
  - TC-IND-003 性质：输入整体上移常数 → 均线同步上移（单调性）

### 1.2 EMA 指数均线
- **公式**：EMA(N,t) = EMA(N,t−1) + α×(C(t)−EMA(N,t−1))，α = 2/(N+1)
- **口径**：**初值取前N根简单均值，不得取首根收盘价**（见深入推导）。
- **对照用例**：
  - TC-IND-004 教科书（工程正文手算）：序列[10,11,12,13,14]，N=3，α=0.5 → 第3根=11、第4根=12、第5根=13
  - TC-IND-005 边界：首根/次根无值；**错误初值对照用例**：首值初值法第3根=10.5，与正确值11的0.5偏差沿递推长期存在（断言两者不相等且正确值递推收敛）
  - TC-IND-006 性质：单调性。

### 1.3 WMA 加权均线
- **公式**：WMA(N,t) = Σ wᵢ×C(t−N+i)/Σwᵢ，权重线性递减，Σwᵢ = N×(N+1)/2
- **对照用例**：
  - TC-IND-007 教科书：序列[10,11,12]，N=3，权重[3,2,1] → (10×3+11×2+12×1)/6 = 64/6 ≈ 10.6667
  - TC-IND-008 边界：窗口未满空值；TC-IND-009 性质：单调性。

## 2. 波动族

### 2.1 标准差（总体口径）
- **公式**：σ(N,t) = √(Σ(Cᵢ−MA)²/N)（**总体**，除以N而非N−1）
- **口径**：行情序列视作已知总体；窗口内全同值时σ=0。
- **对照用例**：
  - TC-IND-010 教科书：序列[1,2,3,4,5]，N=5 → 均值3，σ=√2 ≈ 1.4142
  - TC-IND-011 边界：**全同值→σ=0→布林带宽为0→输出空值而不是零**（除零置零用例）
  - TC-IND-012 性质：价格乘以常数k → σ同步乘以k（量纲）。

### 2.2 ATR 真实波幅（Wilder平滑，N=14）
- **公式**：TR(t) = max(H(t)−L(t), |H(t)−C(t−1)|, |L(t)−C(t−1)|)；**首根无前收，TR=H−L并标记**；ATR = Wilder平滑(TR,N)，平滑系数1/N
- **对照用例**：
  - TC-IND-013 教科书：首根H=11、L=9 → TR=2
  - TC-IND-014 边界：首根标记；窗口未满空值；含空值→空值传播
  - TC-IND-015 性质：与主流软件同参数同区间比对，偏差≤1e-6

## 3. 动量族

### 3.1 ROC 变动率（窗口20）
- **公式**：ROC(N,t) = (C(t)/C(t−N) − 1)×100%
- **对照用例**：
  - TC-IND-016 教科书：序列[10,11]，N=1 → 第2根ROC=10%
  - TC-IND-017 边界：窗口未满空值；C(t−N)=0→除零→输出空值
  - TC-IND-018 性质：**对称性**——正负号翻转时ROC只改变符号。

### 3.2 RSI 相对强弱（Wilder平滑，N=14）
- **公式**：上涨均值U、下跌均值D（各自均值）；RS = U/D；RSI = 100 − 100/(1+RS)；**Wilder平滑系数1/N**（不得用简单均值）
- **口径**：趋势转换处Wilder与简单均值入场时点不同，必须写死Wilder。
- **对照用例**：
  - TC-IND-019 教科书：连续上涨序列（如[10,11,12,13]）→ RSI=100；连续下跌 → RSI趋近0
  - TC-IND-020 边界：含空值→空值传播；全同值→U=D=0→RS未定义→**输出空值**（防"分母写成U−D"类半对公式）
  - TC-IND-021 性质：**对称性**——正负号翻转RSI不变（RSI为比值类，符号翻转后U/D不变）；**对称性检查可抓"分母写成U−D"的半对公式**（工程正文：符号翻转后该指标不再改变符号即暴露）。

## 4. 通道族

### 4.1 BOLL 布林带（N=20，K=2，总体标准差）
- **公式**：中轨=MA(N)；上轨=中轨+K×σ；下轨=中轨−K×σ；带宽=2K×σ/中轨
- **口径**：标准差用**总体**；中轨含当日。
- **对照用例**：
  - TC-IND-022 教科书：σ>0时上下轨=中轨±2σ
  - TC-IND-023 边界：**σ=0→带宽=0→上下轨=中轨→"价格相对带宽位置"输出空值，信号层判定无信号**（除零置零用例，停牌沿用最后价场景真实触发）
  - TC-IND-024 性质：与主流软件同参数同区间比对，偏差≤1e-6

## 5. 量能族

### 5.1 成交量均线（5根/20根两档）
- **公式**：VOL-MA(N) = ΣV(t−N+1..t)/N
- **口径**：绝对量均线仅作参考，**阈值判定必须比值化**（见5.2）。
- **对照用例**：
  - TC-IND-025 教科书：量序列[100,200,300]，N=2 → 第2根=150、第3根=250
  - TC-IND-026 边界：窗口未满空值；量为零→不视为空（零是合法值）
  - TC-IND-027 性质：单调性。

### 5.2 量比（比值化，量能族衍生）
- **公式**：量比 = 当前量能均线值 ÷ 过去一段均值（无量纲倍数）
- **口径**：**>1.5视为放量，<0.7视为缩量**。必须比值化——直接用绝对量阈值，同一套参数在大盘股永不触发、小盘股天天触发，会得到"策略只对小盘股有效"的错误结论，真实原因是量纲。
- **对照用例**：
  - TC-IND-028 教科书：量比=2.0 → 放量；量比=0.5 → 缩量；量比=1.0 → 常态
  - TC-IND-029 边界：过去一段均值为0 → 输出空值
  - TC-IND-030 性质：**量纲**——成交量整体乘以常数，量比不变。

## 6. MACD / KDJ / ADX / CCI / OBV 口径与用例

| 指标 | 公式与口径要点 | 对照用例 |
|---|---|---|
| **MACD**（快12/慢26/信号9，EMA） | DIF=EMA12−EMA26；DEA=EMA9(DIF)；MACD柱=2×(DIF−DEA)；EMA初值取前N根简单均值 | TC-IND-031 教科书：EMA递推手算（N=3简化序列）；TC-IND-032 边界：窗口未满空值；TC-IND-033 性质：与主流软件同参数同区间比对，偏差≤1e-6 |
| **KDJ**（N=9，K=3，D=3） | RSV=(C−L9)/(H9−L9)×100（H9/L9为9日内最高最低）；K=2/3×K前+1/3×RSV；D=2/3×D前+1/3×K；J=3K−2D；**K、D初值50** | TC-IND-034 教科书：首根RSV=(C−L)/(H−L)×100，K/D由初值50递推；TC-IND-035 边界：H9=L9（无波动）→RSV未定义→输出空值；TC-IND-036 性质：与软件比对≤1e-6 |
| **ADX**（N=14） | +DM=H差（正）、−DM=L差（负）；TR；DX=100×|+DI−−DI|/(+DI+−DI)；ADX=Wilder平滑(DX,14) | TC-IND-037 教科书：单调上涨序列ADX计算；TC-IND-038 边界：窗口未满空值；TC-IND-039 性质：与软件比对≤1e-6 |
| **CCI**（N=14） | TP=(H+L+C)/3；CCI=(TP−MA(TP,N))/(0.015×MD)；MD=平均绝对偏差 | TC-IND-040 教科书：TP序列手算CCI；TC-IND-041 边界：MD=0→输出空值；TC-IND-042 性质：与软件比对≤1e-6 |
| **OBV** | 涨累加成交量、跌累减成交量，平盘不变；初值0 | TC-IND-043 教科书：序列[涨,涨,跌,平]→OBV手算；TC-IND-044 边界：首根OBV=0；TC-IND-045 性质：单调性（涨多则OBV上行） |

## 7. 用例执行规范
- 浮点容差：**1e-6**（S00-A4 条件项落地，因子/费率/指标模块覆盖率≥95%的验收含本文件用例）。
- 九个指标全部用例进 S16 回归集；**缺口注入用例（前向填充陷阱）必须进回归集**——只在有停牌标的上触发，多数测试数据是连续交易日，不会自然暴露。
- 对照基准：与主流行情软件（通达信/同花顺）同参数同区间结果比对，偏差≤1e-6；口径差异（总体vs样本、Wildervs简单）由口径表固化并附录进报告（S11）。
