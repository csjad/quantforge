## 1. 训练/验证切分（七三分）

### 1.1 基础规则
- **默认按时间七三分**：前七成训练、后三成验证。
- **切分点固定写入任务快照**，**禁止在验证阶段回头调整**——否则验证集失去样本外意义。
- **判据**：训练段最优参数在验证段的**年化收益 ≥ 训练段的六成**，否则标记**高过拟合风险**。该阈值是本项目给出的**经验下限，非行业标准**，须在报告中注明其性质。

### 1.2 切分三规则（深度展开）
1. **按交易日切分，不按行数切分**——避免因停牌造成的时间扭曲；
2. **训练段与验证段之间留隔离期**，隔离长度 = **最大回看窗口 + 持仓周期**——让验证段起始不携带训练段的状态；
3. **标准化与排名类处理只在训练段拟合，验证段直接套用训练段得到的参数**。

**第三条是过拟合的主要入口**：若在验证段重新计算均值与标准差，指标实际上偷看了验证段自身分布，结果验证集表现优于真实样本外表现。这一点在多轮迭代后会被反复利用——每次调整策略都重算标准化参数，看起来每次都通过验证，**实际上验证集已被当作训练集用了很多次**。

## 2. 过拟合筛查三问

| 问 | 检查 | 通过条件 |
|---|---|---|
| 一 | **参数邻域是否稳定**：最优参数上下浮动一档，指标不塌陷 | 邻域指标 ≥ 基准的八成 |
| 二 | **样本外是否衰减**：验证段与训练段差距是否在阈值内 | 验证年化 ≥ 训练年化的六成 |
| 三 | **去掉最好一年是否仍为正**：剔除收益最高的单年后，年化是否仍大于零 | 剔除后年化 > 0 |

**三问全过方可进入下一步打磨；任一不过即在报告中标记"不具备继续投入价值"。**

## 3. 过拟合三项检查（报告中固定三图，不是可选项）

| 检查 | 方法 | 判据 |
|---|---|---|
| **参数地形** | 把最优参数邻域画成收益曲面（如双均线 10×10 格子图） | 最优点**孤立成尖峰**=过拟合；合格地形=**连续平台**，**平台面积占比 ≥ 两成** |
| **分年度稳定性** | 验证段按年切分 | 只有一年贡献主要收益 → 标记**单年依赖** |
| **交易笔数下限** | 统计验证段成交笔数 | **< 20笔**的结论不作数（少量交易无法区分能力与运气） |

**三项检查成本很低，但能拦掉大部分"看起来很漂亮"的结果。做成报告中的固定三图，出现在每份回测报告里，而不是可选项。** 理由很实际：买家最容易犯的错误就是把单次最优当成策略有效，卖家若把三图放成可选，等于默许这种误读。

### 3.1 参数地形判据（深入推导）
- **形状一 平台**：夏普在矩形区域内稳定在0.8~1.0、边缘逐步下降——存在宽可行域，真实样本外大概率仍在域内；
- **形状二 尖峰**：仅一格夏普1.2、相邻格骤降至0.3——结果由单一组合偶然取得，样本外几乎不可能复现。
- **判据不是看最优点有多高，而是看最优点的四邻域是否仍在均值的八成以上**：四邻域全部达标=平台；两格达标=边缘；一格或零格=尖峰。
- **平台占比** = 夏普 ≥ 全表最高值八成的格子数 ÷ 总格子数。100组中32格达标（32%）判可用；5格（5%）判过拟合。八成阈值的来源是经验：**夏普的抽样误差在百组量级上约为该值的一到两成，取八成相当于要求"落到误差带内"**——更严误杀稳健策略，更松放过过拟合。

### 3.2 分年度稳定性数字形态
- 例一（可用）：验证段五年分年夏普 1.2/0.9/1.1/0.4/1.3 → 去掉最好的一年，剩余均值仍为正，判可用。
- 例二（单年依赖）：1.5/1.4/1.6/−0.8/−1.2 → 两年贡献全部收益、其余三年亏损，判单年依赖。
- **单年依赖的处置不是弃用，而是回到需求层问"这个策略是否本来只适用于某种行情"**——若是，应在文档中**标注适用行情**，而不是包装成全天候策略。**这一点直接决定产品的诚实度。**

## 4. 阈值外置（A4 评审条件）

**过拟合三问与三项检查的全部阈值外置为配置，不写死在代码中**：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 验证收益下限比例 | 0.6 | 验证年化 ≥ 训练年化×此值 |
| 邻域稳定比例 | 0.8 | 邻域指标 ≥ 基准×此值 |
| 平台占比阈值 | 0.2 | 平台面积占比下限 |
| 交易笔数下限 | 20 | 验证段成交笔数下限 |
| 隔离期公式 | 最大回看窗口+持仓周期 | 自动计算 |
| 切分比例 | 0.7/0.3 | 训练/验证 |

## 5. 验证集使用次数记录
- **验证集被反复使用会失去样本外意义**：报告记录**验证集使用次数**并在超限时提示（风险台账 R-003 联动）。每次用验证段调参/重算标准化参数都计数，报告首页展示，超阈值（默认5次）告警"验证集已多次使用，结论可信度下降"。
