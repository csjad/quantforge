# S07-02｜风控规则与拦截用例（六规则×双用例）

- 文档编号：S07-02｜版本：v1.0｜日期：2026-11-13｜主责：角色5（A5），A3/A7 会签
- 工程依据：《工程正文_Doubao》S07 表18/表19、评审条件（A7：**六条规则各写一条拦截用例与一条放行用例**）
- 用例规范：每条用例=构造场景→触发规则→断言拦截行为/放行结果→断言拦截日志（规则编号+原因+持仓快照）

---

## 1. 规则一：标的黑名单

### TC-RISK-001 拦截用例
- **场景**：标的 X 为 ST 股（symbols.is_st=true），策略生成买入信号。
- **断言**：信号被丢弃；拦截日志=规则"标的黑名单"+原因"ST标的"+持仓快照；不进入委托队列。

### TC-RISK-002 放行用例
- **场景**：标的 X 为正常主板股（非ST、上市>60日、未停牌、非退市整理、近20日均额达标），策略生成买入信号。
- **断言**：信号通过黑名单关卡，进入下一关卡（仓位限制）。

## 2. 规则二：单标的仓位上限（30%）

### TC-RISK-003 拦截用例
- **场景**：标的 X 当前持仓市值占总权益 28%，策略再发买入信号，计算后仓位将达 35%。
- **断言**：委托被**削减至上限**（30%），拦截日志=规则"单标的仓位"+原因"超上限削减"+削减后数量；**不是拒单**（事前层允许降级）。

### TC-RISK-004 放行用例
- **场景**：标的 X 当前持仓 10%，新信号计算后仓位 25% < 30%。
- **断言**：委托按计算数量通过，进入集中度关卡。

## 3. 规则三：总仓位上限（100%）

### TC-RISK-005 拦截用例
- **场景**：总仓位已达 98%，新信号将使总仓位超 100%。
- **断言**：**拒绝新开仓**；拦截日志=规则"总仓位"+原因"总仓超限"；按优先级裁剪（多信号竞争时按信号时间/优先级裁剪）。

### TC-RISK-006 放行用例
- **场景**：总仓位 60%，新信号后总仓位 85%。
- **断言**：通过，进入日内亏损关卡。

## 4. 规则四：行业集中度（40%）

### TC-RISK-007 拦截用例
- **场景**：行业"半导体"当前持仓占比 45%，新信号标的属该行业。
- **断言**：**拒绝该行业新开仓**；拦截日志=规则"集中度"+原因"行业超限"。

### TC-RISK-008 放行用例
- **场景**：行业"半导体"持仓占比 30%，新信号标的属该行业，计算后 35%。
- **断言**：通过，进入日内亏损关卡。

## 5. 规则五：日内亏损熔断（5%）

### TC-RISK-009 拦截用例
- **场景**：当日累计亏损达总权益 5.5%（走查场景：前日权益11万、当日亏7000=6.36%）。
- **断言**：**停止开仓**（买入信号一律拒绝，含小额度委托）；熔断状态写入任务状态表；拦截日志=规则"日内亏损"+原因"熔断触发"；**已持仓不强制平仓、卖出信号照常执行**；报告标记熔断区间。

### TC-RISK-010 放行用例
- **场景**：当日亏损 3.5% < 5%，且无连续亏损触发。
- **断言**：信号通过，进入熔断状态检查关卡。

## 6. 规则六：连续亏损（3笔降仓位至5成）

### TC-RISK-011 拦截用例
- **场景**：连续3笔交易亏损，策略再发买入信号。
- **断言**：**单笔仓位被降至50%**（非全拒）；拦截日志=规则"连续亏损"+原因"连亏降仓"。

### TC-RISK-012 放行用例
- **场景**：连续亏损笔数=2（未达3笔），或出现一笔盈利后重置计数。
- **断言**：仓位按模型正常计算，通过。

## 7. 用例执行规范
- **12条用例全部进 S16 回归集**（A7 评审条件落点）；每条用例断言三件套：拦截行为、拦截日志（规则编号+原因+持仓快照）、**被拒信号写入成交日志表**（A3 条件：统计被拒信号的机会成本）。
- **熔断走查用例**（TC-RISK-009 扩展）：熔断后次日继续下跌→允许卖出不允许买入；第三日权益回升→**熔断仍保持，需人工重置**；重置写入审计日志（时间+当时权益）；**熔断区间损失计入最大回撤**（不剔除）。
- **预期拦截量基线回归**（表19）：框架改动后跑标准策略（双均线模板），六规则拦截量与基线比对，**偏离超三成即阻断合并**——这类偏移不导致测试失败，只会让风控悄悄变松，必须靠基线比对发现。
- **波动率仓位溢出用例**：ATR 极小（趋近0）时波动率倒数仓位 → 断言 ATR 下限保护生效 + 30% 硬顶双重限制，不产生超大仓位。
