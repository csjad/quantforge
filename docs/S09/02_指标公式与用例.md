# S09-02｜指标公式与对照用例（A7：十二项各附用例）

- 文档编号：S09-02｜版本：v1.0｜日期：2026-11-13｜主责：角色6（A6），A3/A7 会签
- 工程依据：《工程正文_Doubao》S09（评审条件：**十二项指标各附对照用例**）
- 用例规范：每项指标=构造已知输入→断言计算结果（含口径细节）；空值用例覆盖三类边界

---

## 1. 用例清单（TC-PERF-001~018）

### 1.1 累计收益 / 年化收益（TC-PERF-001~002）
- **TC-PERF-001 累计收益**：净值 1.00→1.12 → 断言累计收益 = 12%（用净值口径，不用期末权益÷初始权益）。
- **TC-PERF-002 年化收益**：250个交易日收益12% → 断言年化 = 1.12^(250/250)−1 = 12%；**区间不足100交易日时断言标注"参考"且不参与排序**。

### 1.2 年化波动 / 夏普（TC-PERF-003~005）
- **TC-PERF-003 年化波动**：日收益标准差σ_日 → 断言年化波动 = σ_日×√250（**断言使用√250而非250**——写成250会夸张数倍）。
- **TC-PERF-004 夏普**：超额收益均值÷超额收益标准差×√250；**分母用超额收益标准差**（无风险取0时与总收益标准差相同，取非零时断言分母切换生效）。
- **TC-PERF-005 权益恒定**：权益恒为10万 → 断言波动为0、**夏普返回空值而非无穷**。

### 1.3 索提诺 / 卡玛（TC-PERF-006~007）
- **TC-PERF-006 索提诺**：构造下行波动小于总波动的序列 → 断言索提诺 ≥ 夏普（分母只计下行波动）。
- **TC-PERF-007 卡玛**：年化收益12%、最大回撤15% → 断言卡玛 = 12%÷15% = 0.8；**分母用峰值口径**（构造峰值抬升场景断言分母变化）。

### 1.4 最大回撤 / 回撤持续期（TC-PERF-008~009）
- **TC-PERF-008 最大回撤**：权益序列 1.0→1.2→0.9→1.1 → 断言最大回撤 = (0.9−1.2)/1.2 = **−25%**（分母用峰值1.2，**不用初始1.0**）；**断言错误做法（初始资金分母）与正确值不同**。
- **TC-PERF-009 回撤持续期**：断言回撤开始与结束日期随最大回撤输出（逐日累计权益+维护历史峰值算法）。

### 1.5 胜率 / 盈亏比（TC-PERF-010~012）
- **TC-PERF-010 胜率**：10笔交易7盈3亏 → 断言胜率70%（**逐笔口径**；断言按日统计混入空仓日的错误结果不同）。
- **TC-PERF-011 盈亏比**：平均盈利3000、平均亏损1000 → 断言盈亏比3.0；**单笔亏损为零 → 断言返回空值而非无穷**。
- **TC-PERF-012 无交易**：成交笔数0 → 断言胜率与盈亏比**返回空值而非0**（零会被误读为"极差表现"，空值才表示"无意义"）。

### 1.6 换手率 / 成交笔数（TC-PERF-013~014）
- **TC-PERF-013 换手率**：期间累计成交金额（双边）÷期间日均持仓市值 → 断言双边口径（**只算单边的错误结果与正确值差一倍**）。
- **TC-PERF-014 成交笔数**：断言成交笔数与成交记录一一对应（**指标计算以成交记录为唯一来源**，A3 条件）。

### 1.7 口径对齐用例（TC-PERF-015~018）
- **TC-PERF-015 年化基准**：250交易日 vs 365自然日 → 断言用250的年化高于用365的（自然日系统性低估）。
- **TC-PERF-016 无风险利率显式**：默认0 → 断言报告显式写出"无风险利率=0"；使用者自设时报告中体现。
- **TC-PERF-017 对账表闭合**：构造本平台12%、对方10.5%的差1.5 → 断言四项拆分（费率0.8+成交价0.6+复权0.1+年化0.0）**相加等于总差**（加不起来即报错）。
- **TC-PERF-018 短区间年化**：3日区间 → 断言年化标注"参考"且不参与排序（防−92%式误导）。

## 2. 用例执行规范
- 18条用例全部进 S16 回归集；浮点容差1e-6。
- **唯一来源断言**：每条用例断言指标值仅由成交记录与权益曲线推导，**不读取策略内部变量**（A3 条件）。
- 报告附录口径：全部公式与参数列入报告附录，允许与第三方对照（口径不一致是高频争议点，对账表为处置手段）。
