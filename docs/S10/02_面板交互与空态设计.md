## 1. 面板五动作（单一页面完成，路径≤3层点击）

面板只做一个页面，但必须完成五个动作：**选策略、设参数、提交任务、看进度、看结果**。

**路径长度不得超过三层点击**。超过三层，使用者会退回命令行，而一旦退回命令行，**面板就沦为装饰**。

| 动作 | 路径示例（≤3层） |
|---|---|
| 选策略 | 面板 → 策略列表 → 选中 |
| 设参数 | 面板 → 参数区 → 调整 |
| 提交任务 | 面板 → 提交按钮（1层） |
| 看进度 | 面板 → 进度区（1层） |
| 看结果 | 面板 → 结果区 → 图表（2层） |

## 2. 进度显示：轮询而非推送

- **轮询间隔2秒**，从任务状态表读取；
- 理由：单机环境下推送需要长连接，**长连接在休眠唤醒后容易挂死**，而挂死的长连接会让界面显示"运行中"却永远不动；
- **轮询的代价是延迟2秒，换来的是永不错觉**。

## 3. 空态与错误态（三态必须给不同文案）

| 空态 | 判定 | 文案 | 为什么必须区分 |
|---|---|---|---|
| **无任务** | 未提交任何回测 | "尚未提交回测" | — |
| **无结果** | 任务已提交、结果未生成 | "任务已提交、结果尚未生成" | — |
| **数据不足** | 所选区间内该标的行情不足 | "所选区间内该标的行情不足，建议缩短回测起点" | **第三种最容易被处理成前两种，而它恰恰是使用者最常遇到的**：选了一只次新股、回测十年，结果自然为空。若提示"无结果"，使用者会以为程序坏了 |

**错误态**：渲染失败/接口超时等，展示错误码三分（鉴权类/限流类/业务类，S08 口径）与建议动作，不静默。

## 4. 渲染预热（深入推导）

**渲染耗时实测拆分**（权益曲线1200点+成交分布200根+参数地形100格）：数据装配约20ms、坐标计算约10ms、绘制约120ms、编码为位图约80ms，**合计约230ms**。

远小于前文所述1~2秒，**差异来自图形库的首次初始化**（约1.2秒，其中库加载与字体度量占约1秒）。**处置：启动时预热一次空图**，把一秒成本挪到启动阶段——**首个请求的响应从1.2秒降到200ms，使用者感知明显不同**。

## 5. 用例要点（S16 落点）

- **TC-VIS-001 渲染进程崩溃不影响任务状态**（A7 条件）：杀掉渲染进程 → 断言回测任务状态不受影响、任务可重试渲染、缓存不污染；
- **TC-VIS-002 降采样一致性**：同一份1万点数据两次渲染 → 断言两次PNG逐像素一致（平台固定降采样规则生效）；
- **TC-VIS-003 缓存命中**：重复请求同一任务同一视图 → 断言直接返回缓存、不重复渲染；
- **TC-VIS-004 清理策略**：30天前的图 → 断言自动删除且PDF保留；磁盘超阈值 → 断言优先删无报告关联中间图；
- **TC-VIS-005 空态三态**：分别构造无任务/无结果/数据不足 → 断言文案各不相同且数据不足不被误报为"无结果"；
- **TC-VIS-006 五动作路径**：断言五个动作均在3层点击内可达。
