## 2. 报告结构（三层：首页 → 正文 → 附表）

### 2.1 首页：配置与免责（**不放置收益曲线**——S00-A6 硬性要求）
首页固定九项：**回测区间、标的池定义、复权模式、费率与滑点模型、成交假设、资金初始值、策略版本与参数快照、数据快照标识、免责声明**。九项缺一，复现即不可能。

### 2.2 正文：第二页起依次
摘要 → 指标表 → 资金与回撤曲线 → 交易明细（**超过50笔折叠为分页表**）→ 风险总结 → 策略弱点 → 优化建议。

### 2.3 五段结构（按**阅读者的怀疑顺序**排列，非重要性）
读者先想知道结论 → 想知道用什么前提得出 → 验证数字 → 怀疑数字稳健性 → 需要一句免责话：

| 段 | 内容 | 篇幅配额 |
|---|---|---|
| 结论摘要 | **只允许3~5句**，必须含收益、回撤、交易笔数、一句"结论的适用边界" | 半页 |
| 前提与配置 | 九项配置全量 | 一页 |
| 结果与指标 | 十二项指标+对账表 | 三页 |
| 稳健性检查 | 地形、分年、笔数（S06 三图） | 两页 |
| 风险声明 | 四条局限 | 半页 |

**配额作用=强制"结论短、证据长"**。摘要超过半页意味着作者在论证而非陈述——摘要的作用是让读者**3秒内决定是否继续读**，超过半页会把读者推走。

### 2.4 表23 章节必备内容与禁区

| 章节 | 必备内容 | 不允许出现 |
|---|---|---|
| 结论摘要 | 收益、回撤、笔数、边界 | **评价性形容词**（"表现优异"无法被检验，一旦被检验就会失效） |
| 前提配置 | 九项配置全量 | 省略费率 |
| 结果指标 | 十二项指标加对账表 | 只给累计收益 |
| 稳健性 | 地形、分年、笔数 | 只给最优组 |
| 风险声明 | 四条局限 | 承诺收益 |

## 3. PDF 生成流水线（中间层方案）

**先生成结构化中间文档，再渲染为 PDF**。中间层的作用：同一份内容可**同时输出 PDF 与网页视图**，且**便于版本比对**。

### 3.1 工程约束五条
1. **字体嵌入**：中文字体显式嵌入，否则无字体环境显示方框——**交付中最常见的低级故障**；
2. **表格不跨页行**：表头行设重复属性、单行设不可拆分（见§3.3）；
3. **图表分辨率不低于150**（dpi）；
4. **页数上限100**：防报告膨胀——区间拉长到十年、标的扩到500只，不设上限会生成800页，没人看却占满磁盘拖慢队列；**超限时自动改为"摘要版+明细附件"**；
5. **生成失败必须回滚不留半成品**（见§3.4）。

### 3.2 生成耗时账（工程正文实测口径）
20页报告、4张图、6张表：数据装配约200ms、表格排版约300ms、图片嵌入约400ms、**字体子集与打包约3秒**、写盘约100ms，**合计约4秒**。
- **3秒字体子集是大头**：处置=**限制嵌入字符集**（只嵌入文中实际出现的字）+保留备用字体族；若不限制，单份报告从2MB涨到8MB、生成耗时翻倍。

### 3.3 表格跨页处置
20行成交明细表跨页时，表头不重复则第二页读者看不懂列义。**表头行设重复属性+单行不可拆分**，两条属性生成时写入。**验收方式：生成一份必然跨页的报告，翻到第二页截图核对**——属性写错常表现为"Word里正常、PDF里丢失"，截图核对比任何断言可靠。

### 3.4 失败回滚实现
**先写"临时名+随机后缀"→ 校验可打开（尝试读取页数，读不出即判定损坏）→ 原子重命名**。中途失败删除临时文件，正式路径保持旧版本。成本约100ms，**换"报告下载打不开"这类最影响交付体验的问题归零**。

### 3.5 报告版本留存
- 报告关联**原始回测任务ID**（任务标识+数据快照号+参数哈希，与 S06 分片标识同源）；
- 每次生成保留版本号，中间层文档与PDF同版本留存，**便于版本比对**；
- 中间层文档即网页视图数据源（同一份内容双输出）。
