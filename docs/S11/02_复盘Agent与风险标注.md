# S11-02｜策略复盘 Agent 与风险标注

- 文档编号：S11-02｜版本：v1.0｜日期：2026-11-13｜主责：角色6（A6），A4/A5 会签
- 工程依据：《工程正文_Doubao》S11 复盘结论、复盘四问；S06 过拟合筛查联动

---

## 1. 复盘原则：基于规则，而非自由生成

**复盘模块基于规则而非自由生成**：读指标字典，**命中预设判据后输出对应结论**。规则式的好处：每条结论可复算、可追溯、不产生幻觉；自由生成的结论无法检验，一旦被检验就会失效（与表23"摘要禁评价词"同一逻辑）。

## 2. 五条判据（工程正文冻结，阈值外置为配置）

| 判据 | 条件 | 输出结论 |
|---|---|---|
| 1 | 最大回撤 > 20% 且 卡玛 < 0.5 | "风险收益比不足" |
| 2 | 交易次数 < 30 | "样本不足，结论不成立" |
| 3 | 训练段与验证段年化差距 > 40% | "存在显著过拟合" |
| 4 | 换手率极高 且 收益集中在少数几笔 | "收益依赖极少数事件" |
| 5 | （扩展）验证段成交笔数 < 20 | "样本不足，结论不作数"（S06 三项检查联动） |

**每条结论必须标注风险等级，并附一条"如何进一步验证"的具体建议。**

**风险等级标注口径**（与 S00 风险台账分级对应）：
- **高**：结论不成立级（样本不足、显著过拟合、收益依赖极少数事件）——不采纳该结论；
- **中**：结论可用但需警惕（风险收益比不足）——标注使用边界；
- **低**：无命中判据——正常结论。

**每条结论后附"仅为统计描述"说明**——防复盘结论被当作投资建议（工程正文风险项）。

## 3. 复盘四问（固定回答，数据支撑逐问落盘）

| 问 | 数据支撑 | 分桶方式 |
|---|---|---|
| 1. 信号在哪一阶段贡献收益 | 收益归因 | **按持仓期分桶** |
| 2. 亏损集中在哪类行情 | 亏损分布 | **按行情状态分桶：趋势、震荡、极端** |
| 3. 参数是否踩在边界 | 参数边界检查 | 最优参数距上下界的**相对距离** |
| 4. 样本外是否衰减 | 训练/验证比对 | **同口径指标**（S06 七三分切分） |

**四问的价值在于把"策略能不能用"这个模糊问题拆成四个可回答的问题。**
**四问里只要有一问答不上来，这份复盘就没有完成**——答不上来往往意味着对应的数据没有落盘，而数据没落盘说明该项从未被当作必需项。

## 4. 风险总结章节的强制内容（A5 条件项）

**风险总结章节必须包含熔断区间说明**（S07 闭环项落地）：熔断区间起止日、当日亏损幅度、被熔断拒绝的信号数量、熔断损失是否计入最大回撤（不剔除原则）。

## 5. 过拟合标注联动（S06→S11）

- 过拟合三问（邻域稳定/样本外衰减/去掉最好一年仍为正）结果入报告稳健性段；
- 三项检查（地形/年度/笔数）三图在报告第二页（前端，非附录）；
- 阈值全部外置配置（S06 六项阈值配置口径）。

## 6. 用例要点（S16 落点）
- **TC-REP-001~005**：五条判据各构造触发场景，断言结论文本+风险等级+验证建议三件套齐备；
- **TC-REP-006**：四问数据缺失场景，断言复盘标记"未完成"而非静默跳过；
- **TC-REP-007**：风险总结含熔断区间说明（构造熔断场景断言）；
- **TC-REP-008**：结论后附"仅为统计描述"声明（防投资建议误读）。
