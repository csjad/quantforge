## 2. 断言写法要求

**断言必须带数值边界与失败信息。** 示例："成交笔数等于零，**若不为零输出前三条成交的日期与价格**"。
**只写"应为零"的断言在失败时无法定位原因，而定位成本往往高于测试本身的编写成本。**

**容忍度为零**：六场景断言都是"零或非零"的离散判定，不存在中间态；**与性能类断言不同，后者必须有容忍带**。

## 3. 关键走查（工程正文推导）

### 3.1 涨停场景成交判定
标的B前收10元，主板涨停价11元。第1日开盘即11元、全日无回落=一字板。策略昨日买入信号，今日撮合：方向买、开盘价=涨停价 → **判定不可成交，保留委托**；收盘后委托作废并记录"涨停未成交"。
**次日开盘10.5元，委托已作废，不再顺延**——A股委托当日有效，**跨日顺延会让回测产生一条现实中不存在的持仓机会**。连续10日一字板 → 10日全部记录不成交，**成交笔数为零**（S00-A7 涨停专项用例判据）。

### 3.2 跌停场景
跌停价9元，持仓需卖出止损。开盘即9元、全日无回升 → **不可成交**；持仓继续持有，止损信号保留，次日重新判定。
**不允许"按跌停价强行成交"**——真实市场一字跌停排队也未必成交；**强行成交会显著改善回测的下行保护效果，这正是它危险的原因：让策略看起来在极端行情中能止损，而现实中不能**。

### 3.3 停牌场景估值
停牌第30日，**沿用第29日最后有效价估值**，报告标注"**停牌沿用**"。
**六类里最容易做错的是停牌估值**：停牌期间用零价估值 → 权益曲线瞬间归零再跳回 → **最大回撤指标被彻底污染**。停牌超3个月仍在池内 → 标的池规则排除，**但已有持仓不清算**（避免停牌期间虚假成交）。
