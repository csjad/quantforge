## 1. 兼容性验证方式（两级）

### 1.1 一级验证（数据兼容）
- **方法**：**随机抽3份V1快照，V2直接打开并查询**；
- **成本**：3份×约2分钟=**约6分钟**；
- **通过判据**：快照可打开、核心查询返回行数一致。

### 1.2 二级验证（结果兼容）
- **方法**：**五模板策略在 V1 与 V2 各跑一遍，比对十二项指标**；
- **成本**：5模板×2遍×约4秒=**约40秒**；
- **通过判据**：核心指标偏差**≤千分之五**（S09 对账表口径）；
- **关键纪律**：**二级验证是回归测试的一部分，不是一次性动作，每次 V2 内部改动都要重跑**——否则二级承诺会在某次重构中**静默失效**。

**两项合计不到7分钟，可在每次改动后执行，因此二级验证纳入日常回归，而非发布前专项。**

### 1.3 三级验证（行为兼容）——不承诺
明确不承诺：信号时点与成交笔数完全一致（调仓逻辑必然改变部分信号时点，声明不承诺让变化成为预期）。

## 2. 资源预算算式（深入推导口径）

### 2.1 磁盘增量
- 组合调仓每日持仓明细：单任务 **5000行 × 约100字节 = 500KB**；
- 按1000任务/年计：**约0.5GB/年**；
- 组合持仓表常驻：**约20MB**；
- **两项合计不到总量2%，符合一成上限**（磁盘增量超总量一成→拆分到V3）。

### 2.2 内存增量
- 组合模式10标的并行：**内存估算从1.5GB上升至4GB**；
- **须在 S21 实测验证**；**不达标则限制组合规模为5标的**（5标的约2GB，回落至单任务内存上限内）。

### 2.3 教程增量
- 新增3章约15页；**未超4章上限**，允许同版更新目录；
- **超4章须同步重写目录**，防教程结构随迭代逐步崩坏。
