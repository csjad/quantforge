# S23-02｜回放状态一致性检测与用例

- 文档编号：S23-02｜版本：v1.0｜日期：2026-11-13｜主责：角色7（A7），A3/A6 会签
- 工程依据：《工程正文_Doubao》S23 状态一致性、跳转边界、A7 条件项（**验证回放不产生任何主库写入**）

---

## 1. 状态一致性规则（回放正确性的核心）

**回放窗口内显示的持仓与资金必须是该日真实状态，而不是最终状态。**

**检测方式**：在任意一日对比**三处数据——权益曲线该点、状态序列该日、成交明细累计——三者必须自洽**。
**不自洽即判定回放状态有误**，而这类错误**常见于"曲线用最终序列、持仓用当日状态"混用**。

**正确实现路径**：**先从结果中还原每日状态快照，再按日回放**（而非移动视窗直接画最终序列）。

## 2. 跳转边界

**跳转到回测区间外的日期应提示"超出区间"而不是显示空白。**
**显示空白会让使用者以为数据丢失**。

## 3. 隔离验证（A7 条件项）

**验证回放不产生任何主库写入**：
- 回放使用**独立临时账户**，主库（PG 业务库/结果库/行情库）**零写入**；
- 回放读取**状态序列**（回测时落盘），不读原始行情（幂等保证）；
- 手动干预（买入/卖出/改现金）只作用于临时账户，操作清单单独留存。

## 4. 用例清单（TC-REPLAY-001~006）

### TC-REPLAY-001 倍速/暂停/步进/跳转四操作
- **场景**：逐日档执行播放、暂停、步进、跳转。
- **断言**：四种操作均生效；跳转到区间外日期提示"超出区间"而非空白。

### TC-REPLAY-002 状态一致性三处自洽
- **场景**：任意一日，比对权益曲线该点、状态序列该日、成交明细累计。
- **断言**：三处自洽；**不自洽即判定回放状态有误并报错**（防"曲线用最终序列、持仓用当日状态"混用）。

### TC-REPLAY-003 手动干预三操作+操作清单
- **场景**：回放中手动买入/卖出/修改现金。
- **断言**：三操作生效于临时账户；**每次记录操作时间/类型/影响金额**；**回放结束输出操作清单**；操作不得隐藏。

### TC-REPLAY-004 快照保存与加载
- **场景**：回放中保存快照（账户/持仓/时钟/策略状态），加载后从该点继续。
- **断言**：快照四要素完整；加载后状态与保存时一致；**"如果当时这样做"可复现**。

### TC-REPLAY-005 回放零主库写入（A7 条件项）
- **场景**：回放全程（含手动干预、快照、跳转）监控主库。
- **断言**：**主库零写入**（PG 业务库/结果库/行情库）；回放只读状态序列；隔离硬约束生效。

### TC-REPLAY-006 回放与正式任务隔离
- **场景**：回放运行期间提交正式回测任务。
- **断言**：回放使用独立临时账户，**不影响正式回测任务**（不占正式队列、不污染正式账户）。

## 5. 用例执行规范
- TC-REPLAY-001~006 进 S24/S25 回归；**TC-REPLAY-005（零主库写入）为 A7 条件项核心**；
- 状态一致性检测在每次回放加载时自动执行（三处自洽），不依赖人工抽查；
- 倍速超过4倍的跳帧现象在面板提示"超过4倍画面跳帧"（时长预算口径，S23-01 §7）。
