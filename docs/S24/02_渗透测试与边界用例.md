# S24-02｜组合模式渗透测试与边界用例

## 1. 渗透测试用例（表39 五类 + 四攻击面）

### TC-SEC2-001 组合参数绕过（标的数上限→内存耗尽）
- **手段**：提交组合任务，标的数超过上限（10只→11只），或构造超大组合参数。
- **期望**：**拒绝并记录**（组合规模上限生效，S20 H-S20-01 内存验证联动）。

### TC-SEC2-002 调仓顺序资金竞争
- **手段**：构造买入信号触发调仓，同时多个标的竞争资金。
- **期望**：**拒绝并记录**（两阶段决策+守恒检查拦截，S21/S20 C-035）。

### TC-SEC2-003 回放接口写主库
- **手段**：通过回放接口尝试写入主库（PG业务库/结果库/行情库）。
- **期望**：**拒绝并记录**（回放独立临时账户+禁止写主库，S23 隔离硬约束）。

### TC-SEC2-004 ETF 分红参数注入非法值
- **手段**：注入非法分红参数（负金额/非数值/超上限）。
- **期望**：**拒绝并记录**（分红参数强校验，S22）。

### TC-SEC2-005 权重篡改
- **手段**：策略直接写权重表。
- **期望**：**拒绝并记录**（控制面与数据面分离，策略只能经受控接口声明意图）。

### TC-SEC2-006 属性注入
- **手段**：构造异常涨跌幅属性（ETF 标为20%而实际10成）。
- **期望**：**硬拦截**；**属性表与数据源校验：每日收盘后比对涨停价与属性反推涨停价，不一致告警**（S24-01 §8）。

### TC-SEC2-007 状态越权
- **手段**：策略尝试读取账户状态。
- **期望**：**拒绝**（策略进程无账户接口，S05 回放隔离延续）。

### TC-SEC2-008 分红前视
- **手段**：分红按公告日入账（非除息日）。
- **期望**：**断言失败**（分红必须发生在除息日，S22 时序硬约束）。

### TC-SEC2-009 越权导出
- **手段**：面板尝试导出策略源码。
- **期望**：**拒绝**（源码不外泄，S15 不审计清单延伸）。

### TC-SEC2-010 组合模式熔断渗透（A5 条件项）
- **手段**：组合模式下构造熔断触发场景，同时尝试调仓买入/集中度超限调仓。
- **期望**：**熔断规则同样生效**（熔断期间禁止调仓买入，S21 A5）；**集中度规则纳入渗透**（行业超限调仓被拒）。

## 2. 边界测试六条（判据=资金守恒）

| # | 边界场景 | 构造 | 判据（资金守恒） |
|---|---|---|---|
| TC-EDGE-001 | **标的一只** | 组合仅1只标的 | 期初权益=期末权益±盈亏±成本 |
| TC-EDGE-002 | **标的十只** | 组合10只标的（上限内） | 同上 |
| TC-EDGE-003 | **标的超上限** | 组合11只标的 | 拒绝入池+记录；守恒式仍成立 |
| TC-EDGE-004 | **全部停牌** | 组合全部标的停牌 | 持仓不动、估值沿用（S16 停牌口径）；守恒成立 |
| TC-EDGE-005 | **全部涨停** | 组合全部标的涨停 | 卖出不成交（非强行）、买入按回款缩减（S21）；守恒成立 |
| TC-EDGE-006 | **现金为零** | 组合现金为0 | 买入委托拒绝（无资金）；守恒成立 |

**判据统一**：**任一情形下资金守恒公式成立，即期初权益等于期末权益加减盈亏与成本**（S03 三守恒式延伸至组合）。

## 3. 回归执行规范
- 表39 五用例+四攻击面+六边界**全部纳入回归**（长期运行）；
- **TC-SEC2-010（熔断+集中度渗透）为 A5 条件项落点**；
- 七项回归（S24-01 §6）合计约1分钟，**每次提交前执行，无跳过理由**；
- V1 的 S16 全部用例在 V2 重跑，**通过率≥95%**，未通过逐条说明预期变更或缺陷。
