## 3. 结构原则（深度展开）

**V2 教程增三章（组合回测、ETF与分红、回放面板）均为新增而非改写**——**V1 的叙事顺序以单标的为主线，硬插入组合内容会打乱节奏**。
**新增章节置于原第十章之后，形成"进阶篇"。**

**进阶篇必须独立可读**：**不允许出现"参见前文第三十页"的交叉引用超过三处**。
**理由：教程被分割阅读的概率远高于通读，交叉引用一多，跳读者就会断。**

## 4. 口径统一（硬约束）

**新增章节里出现的所有数字口径必须与 V1 一致**：
- 同样 **250 交易日年化**；
- 同样 **无风险利率取零**；
- 同样 **费率默认**。

**若不一致，读者会发现同一策略在第九章与第十三章得到不同夏普，然后失去对全书数字的信任**。

## 5. 每章四段模板（沿用 S19 规范）

1. **本节目标**（三条可验证）；
2. **操作步骤**（含菜单路径与具体参数值）；
3. **常见报错与修复**（不少于5条，报错原文/原因/修复/预防）；
4. **完成标志与自测题**。

**A6 条件项**：**两章均附"常见误解"小节**——在四段模板之外增设，专门澄清易被误读的概念。
