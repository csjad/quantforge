## 2. 训练流水线（五步）

| 步 | 动作 | 关键约束 |
|---|---|---|
| **1 样本构造** | **按日期滚动**，每条样本=**窗口内特征 + 未来N日收益标签** | **窗口边界严格按日期，不允许跨段取数** |
| **2 切分** | 训练段与验证段**时间不重叠** | **切分沿用 S06 规则，隔离期长度取标签跨度**（防验证段携带训练段状态） |
| **3 训练** | 梯度提升树/小型时序网络训练 | **随机种子固定**（可复现，A7 条件）；训练与回测分离（S26） |
| **4 评估** | 单因子检验（S26 判据：有成交/夏普正/分十组单调）+ IC/IR | 评估不达标→不进入回测 |
| **5 导出** | 模型导出为**可加载文件+元数据** | **元数据缺失禁止进入回测**（无法判断是否泄露） |

## 3. 特征集（四类共十二项）

| 类 | 特征 |
|---|---|
| **价格类** | 收益率、均线偏离、波动率 |
| **量能类** | 量比、换手、成交额分位 |
| **形态类** | 上下影线占比、连续同向天数 |
| **市场类** | 指数收益、行业相对强弱 |

**全部为比率型**——**避免绝对价格导致跨期不可比**。

## 4. 产出格式（模型元数据六项）

模型导出为可加载文件，附元数据：
1. **训练区间**（C-036 校验：完全早于回测区间）；
2. **特征列表**；
3. **标签定义**（未来N日收益，N≤调仓周期）；
4. **评估指标**（单因子检验结果+IC/IR）；
5. **随机种子**（固定，A7 可复现验证）；
6. **训练配置**（模型类型/参数）。

**元数据缺失的模型禁止进入回测**——因为无法判断是否泄露。

## 5. 风险台账补充（S27 两项）

| 风险 | 应对 |
|---|---|
| **特征标准化跨越切分点导致泄露** | **标准化参数只用训练段拟合**，验证段直接套用（与 S06"标准化只在训练段拟合"一致） |
| **随机种子未固定导致结果不可复现** | **固定并写入元数据**；A7 验证固定种子下两次训练结果完全一致 |

## 6. 评估归档（复现一次训练的最低要求）

**评估归档必须存四件东西：模型文件、特征清单、训练配置、评估指标。四件齐全才能复现一次训练。**
