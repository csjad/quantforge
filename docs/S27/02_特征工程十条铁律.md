# S27-02｜特征工程十条铁律

- 文档编号：S27-02｜版本：v1.0｜日期：2026-11-13｜主责：角色4（A4），A7 会签
- 工程依据：《工程正文_Doubao》S27 特征工程十条铁律、标签构造、评估归档

---

## 1. 十条铁律（前三条最关键）

### 铁律1：所有特征只用历史窗口计算，禁用未来信息
与 S04 因果性约束同源。**特征在 t 时刻只能使用 t 及之前的数据**，窗口边界严格按日期，不允许跨段取数。

### 铁律2：滚动标准化只用训练段统计量
**防止偷看验证段分布**。标准化参数（均值/方差）只在训练段拟合，验证段直接套用——全样本标准化是 V3 最常见泄露形态（S26 三类泄露第1类）。

### 铁律3：标签构造必须按"预测下一期收益"，且标签时间跨度不得超过调仓周期
**否则标签包含尚未发生的持仓期**。标签 N 日收益的 N 必须≤调仓周期（如月度调仓则 N≤1个月），防止标签"看见"调仓周期之外的未来。

### 铁律4：缺失值用显式标记而非均值填充
均值填充会引入虚假的"正常值"，污染分布。缺失须显式标记（空值传播，S04 口径）。

### 铁律5：类别特征独热编码以固定字典
字典固定才能跨版本可比；字典漂移会导致特征含义变化。

### 铁律6：特征按窗口对齐到交易日
以交易日索引为基准（不按自然日），避免停牌造成的时间扭曲（S06 切分规则同源）。

### 铁律7：极端值用截尾而非删除
删除极端值会改变样本分布；截尾保留样本量、控制离群影响。

### 铁律8：特征名不随版本变化
特征名是跨版本比对的锚点；改名会让历史模型与新模型不可比。

### 铁律9：每条特征须附一行经济含义说明
**第七条（即本条）容易被当成形式主义，但它的作用是阻止"无意义的数学组合"进入模型**。**一条特征若写不出经济含义，通常是两个无关量的偶然相关——这类特征在样本内有效、样本外失效，且失效时无法解释原因**。

### 铁律10：特征全部为比率型，避免绝对价格跨期不可比
与 S27-01 特征集设计一致（价格类用收益率/偏离度/波动率，不用绝对价）。

## 2. 标签构造约束（铁律3 展开）

| 约束 | 说明 |
|---|---|
| 预测目标 | 未来 N 日收益（标签） |
| **N ≤ 调仓周期** | 月度调仓→N≤1个月；防止标签包含尚未发生的持仓期 |
| 标签对齐 | 标签的起始日=样本特征窗口结束日之后的第一个交易日 |
| 标签缺失 | 停牌/数据缺失导致的标签缺失→显式标记，不填充 |

## 3. 评估归档四件（复现一次训练的最低要求）

**评估归档必须存四件东西：模型文件、特征清单、训练配置、评估指标。四件齐全才能复现一次训练。**

**缺任何一件=该次训练不可复现**，与 S27-01 元数据缺失禁止入回测同源。

## 4. A7 条件项落实

**验证固定种子下两次训练结果完全一致**：
- 随机种子写入模型元数据（S27-01 §4）；
- 用例：同一配置同一数据同种子训练两次→断言两次评估指标完全一致（数值容差1e-6）；
- 种子未固定→训练被拒绝。

## 5. 用例要点（S29 回归落点）
- **TC-FE-001 特征只用历史窗口**：构造 t 时刻特征引用 t+1 数据→未来函数扫描报错；
- **TC-FE-002 标准化只用训练段**：全样本标准化→检测报错，训练段拟合+验证段套用通过；
- **TC-FE-003 标签跨度≤调仓周期**：标签 N>调仓周期→拒绝；
- **TC-FE-004 种子固定可复现**：同种子两次训练一致（A7 条件）；
- **TC-FE-005 特征经济含义**：无经济含义说明的特征→入库拒绝（防无意义数学组合）。
