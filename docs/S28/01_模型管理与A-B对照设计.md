## 2. 版本管理

**每个模型记录四要素：版本号、训练区间、评估指标、所属因子。**
- **版本不可覆盖，只能新增**；
- **回测任务在提交时绑定模型版本，任务结束后锁定，禁止事后替换**——保证报告与结果可追溯到具体模型版本。

### 2.1 模型版本三段标识（防"同名不同内容"）

版本标识=**"算法族、训练快照号、随机种子"三段**。
- **三段相同的模型视为同一版本，可互换使用**；
- **任一不同则为不同版本，必须分别登记**；
- **作用**：防止"同名不同内容"——两次训练种子不同→模型权重不同，但文件名可能一致→**结果无法复现**。

### 2.2 版本淘汰（三规则）

| 规则 | 处置 |
|---|---|
| **连续三次评估低于基线** | 标记**待淘汰** |
| **被新版本全面超越** | **退役** |
| **退役后** | **保留模型文件但不再参与推理** |

**保留而非删除**：报告中可能引用旧版本结果，**删除会导致历史报告无法复现**。

**淘汰实际节奏**：**模型因子平均三个月衰减一次**。**淘汰检查按月做，六个月未更新且未复检的模型标记为"待复检"，而非直接淘汰**。

## 3. A/B 对照机制

**同一策略、同一数据、同一区间，只替换模型版本，输出两份结果并生成差异表。**

**对照判据不是"哪个收益高"，而是"差异是否稳定"**：**分年度看两模型胜负是否一致；一致才说明差异来自模型本身，而非某一年运气**。

### 3.1 A/B 对照四条硬约束（任一不同，对照结论即无效）

1. **同数据快照**；
2. **同费率与滑点配置**；
3. **同回测区间与标的池**；
4. **同评估脚本**。

**实践中最常见的违规**："模型A用最新数据、模型B用旧数据"——**看起来"各自最优"，实际比较了两个不同的世界**。
**因此对照功能必须在界面上锁定四组配置，不允许逐项修改**。

## 4. 对照报告（三块内容）

| 块 | 内容 | 用途 |
|---|---|---|
| **总体指标对比** | 十二项指标逐项差异 | 总体差异 |
| **分年度对比** | 各年度两模型胜负 | **判据=差异是否稳定** |
| **换手与成本对比** | 换手率、调仓成本 | **识别"某模型靠极高换手获得超额，成本一加就消失"** |

**表43 A/B 对照记录字段**：版本标识（三段式）、快照号（数据版本）、区间（起止日）、指标组（十二项）、差异（逐项差值）、**结论（采用、并列、淘汰）**。
