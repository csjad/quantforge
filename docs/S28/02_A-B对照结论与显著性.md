# S28-02｜A/B 对照结论写法与差异显著性

- 文档编号：S28-02｜版本：v1.0｜日期：2026-11-13｜主责：角色4（A4），A6 会签
- 工程依据：《工程正文_Doubao》S28 结论三档、差异显著性、对照成本、A6 条件项

## 1. 对照结论三档（只允许三种取值）

**结论只允许三种取值：采用、并列、淘汰。不允许"略好"这类模糊表述。**

**理由**："略好"在实际决策中**等于没有信息**，而它会让使用者产生"已经更好"的错觉，**延续一个未经判定的选择**。

## 2. 差异显著性三档

十二项指标逐项比较：

| 差异区间 | 判定 | 处置 |
|---|---|---|
| **< 千分之五** | **无差异** | 视为并列 |
| **千分之五 ~ 2%** | **可能差异** | **须扩大区间复核** |
| **> 2%** | **实质差异** | 进入采用/淘汰判定 |

**三档判定的作用**：避免"千分之六的差异被当成重大发现"——**这类微小差异在扩大区间复核后往往消失**。

## 3. 一次 A/B 的成本与节奏

**两版本各跑一遍五年日线，每次约4秒，合计约8秒。**
**成本极低，因此 A/B 应当在每次模型更新后都做，而不是只在大版本做。**

## 4. A6 条件项：对照次数标注

**对照报告标注对照次数**：
- **每次 A/B 对照记录次数**；
- **报告中提示**（对照次数超阈值时告警"对验证集的过度使用风险"）；
- **目的**：防 A/B 被用于反复挑选最优模型后直接上线，导致验证集失效（S28 风险项）。

## 5. 用例要点（S30 回归落点）

- **TC-AB-001 四硬约束锁定**：尝试逐项修改对照配置（数据快照/费率/区间/评估脚本）→拒绝，界面锁定四组配置；
- **TC-AB-002 对照判据=稳定性**：构造两模型分年度胜负不一致场景→结论不判"采用"（差异不稳定=某一年运气）；
- **TC-AB-003 差异显著性三档**：构造差异<千分之五/千分之五~2%/>2%三场景→分别判定无差异/可能差异/实质差异；
- **TC-AB-004 结论三档**：对照结论只允许采用/并列/淘汰，"略好"类表述被拒绝；
- **TC-AB-005 版本锁定**：任务提交后尝试替换模型版本→拒绝（禁止事后替换）；
- **TC-AB-006 对照次数记录**：多次对照→报告标注次数+超阈值告警（A6 条件）。
