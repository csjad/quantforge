# S29-02｜模型安全用例与因果复算方法

- 文档编号：S29-02｜版本：v1.0｜日期：2026-11-13｜主责：角色7（A7），A4/A5 会签
- 工程依据：《工程正文_Doubao》S29 表44、因果复算、拒绝率阈值；评审条件（A4：**模型文件上传时做体积与结构检查**）

## 1. 表44 模型安全用例（五类，预期拒绝/告警/断言失败）

| 用例 | 手段 | 期望 |
|---|---|---|
| **样本投毒** | 注入极端样本 | **扫描告警** |
| **时间错位** | 次日价算当日 | **复算不一致拒绝** |
| **窗口越界** | 声明与实现不符 | **断言失败** |
| **标签泄漏** | 当期收益入特征 | **拒绝入库** |
| **统计量污染** | 全区标准化 | **拒绝入库** |

**TC-SEC3-001~005** 对应表44，全部进回归长期运行。

## 2. 因果复算方法（特征入库强制）

**做法**：**随机抽三个时点，取该时点及之前的数据重算特征，与入库特征逐值比对。**
- **偏差容忍万分之一（浮点）**；
- **抽三个时点能检出约八成的时间错位类问题**——错位会让整列数值系统性偏移；
- **特征入库时强制跑一遍**，四种注入形态（时间错位/窗口越界/标签泄漏/统计量污染）全部作为拒绝条件。

## 3. 样本投毒检出形态（启发式）

**注入10条极端样本后，模型对特定标的的预测在10个连续交易日保持同号。**
**正常模型不会如此稳定，因此"连续十日同号"可作为一条启发式告警。**

## 4. 拒绝率阈值

- **特征入库拒绝率正常应低于2%**；
- **若某批次超过10%** → **说明数据源或特征定义出了系统性问题，应整批退回**（不逐条修补）。

## 5. A4 条件项：模型上传体积与结构检查

**模型文件在上传时做体积与结构检查**：
- **体积检查**：体积异常大于参数量预期→判定可疑（数据泄露测试，S29-01 §5）；
- **结构检查**：文件结构与元数据六项（训练区间/特征列表/标签定义/评估指标/随机种子/训练配置）完整性校验；
- **不合格拒绝上传**，合格方可入库模型注册表（S28）。

## 6. 用例执行规范
- TC-SEC3-001~005 进回归；**因果复算在每次特征入库自动执行**（不依赖人工）；
- 拒绝率监控每批次记录，超10%整批退回+告警；
- 上传检查（体积+结构）在模型入库入口强制（A4 条件）。
