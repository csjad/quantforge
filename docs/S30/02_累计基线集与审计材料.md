# S30-02｜累计基线集与审计材料（A3 条件项）

- 文档编号：S30-02｜版本：v1.0｜日期：2026-11-13｜主责：角色7（A7），A3 会签
- 工程依据：《工程正文_Doubao》S30 累计基线集、四份材料、放行记录；评审条件（A3：**绑定信息写入任务快照而非仅写入结果表**）

---

## 1. 累计基线集十三项（每轮改动全跑）

| 来源 | 基线项 | 耗时 |
|---|---|---|
| **V1** | 五模板策略结果（双均线/布林带/RSI/ATR/多因子） | 各4秒 |
| **V2** | 组合资金守恒 / ETF费用反算 / 分红市值守恒 / 回放状态一致 | 各5秒 |
| **V3** | 模型单因子检验 / 因果复算 / A/B四硬约束 / 版本锁定 | 各8秒 |
| **合计** | **13项** | **约72秒** |

**纪律**：每轮改动全跑13项；**只跑本版新增用例=V1功能静默退化的通道**（退化常发生在共享组件，如特征生成改缓存键→V1因子结果变化）。

## 2. 审计四份材料（缺一不通过）

| 材料 | 必含内容 | 判定作用 |
|---|---|---|
| **需求对照表** | V1~V3 需求逐条对齐实现状态 | 判定**完成度** |
| **回归报告** | 十三项基线结果+偏差 | 判定**退化** |
| **遗留项清单** | 未闭环项（编号/描述/影响/责任阶段/截止条件） | 判定**风险** |
| **变更记录** | 变更五项（日期/影响面/是否破坏兼容/迁移动作/回滚方式） | 判定**影响** |

## 3. A3 条件项：绑定信息写入任务快照

**模型与策略的绑定信息写入任务快照，而非仅写入结果表。**
- **理由**：结果表可能被清理/归档，快照与任务同生命周期（S12 任务快照机制）；**只写结果表→任务归档后绑定信息丢失→审计点1（绑定可追溯）无法验证**；
- **快照内容**：模型版本（三段标识）+策略标识+数据快照号+训练区间引用；
- **检查**：审计时从任务快照可完整还原"哪个模型→哪个策略→哪个数据快照"。

## 4. 放行记录五项（趋势表）

**每次放行记录五项：日期、版本、回归结果、遗留数、教程是否更新。**
**五项成表可看出趋势：若遗留数逐版上升，说明迭代节奏过快**——据此调整迭代节奏而非继续堆功能。

## 5. 用例要点（S30 回归落点）
- **TC-REG-001 累计基线全跑**：改动后13项全绿，任何一项不绿即阻断；
- **TC-REG-002 退化检测**：构造缓存键调整场景，断言V1基线偏差可检出（防静默退化）；
- **TC-AUDIT-001 审计三处**：绑定可追溯（快照验证）/训练区间全早于回测/版本未事后替换，任一不满足判定不可发布；
- **TC-AUDIT-002 四材料齐备**：缺任一材料审计不通过；
- **TC-AUDIT-003 放行三条件**：13项全绿+遗留≤5+兼容变更入教程。
