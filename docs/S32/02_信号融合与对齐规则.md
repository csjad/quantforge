# S32-02｜信号融合规则与对齐用例

- 文档编号：S32-02｜版本：v1.0｜日期：2026-11-13｜主责：角色3（A3），A4/A7 会签
- 工程依据：《工程正文_Doubao》S32 融合严格定义、对齐规则、预热影响；评审条件（A4：**未完成的大周期K线在上下文中不可访问**；A7：**为对齐写"边界前、边界时、边界后"三时点用例**）

---

## 1. 信号融合规则（大周期方向三分）

| 大周期方向 | 小周期允许动作 |
|---|---|
| **多头** | **小周期允许买入** |
| **空头** | **小周期允许卖出** |
| **中性** | **忽略全部小周期信号** |

- **小周期无法单独开仓**——避免"小周期噪声主导结果"；
- **盘中切换钉死**：**日线收盘才切换，盘中不变**——否则同一天内建仓又被清仓的抖动；
- **模板说明必写**：**大周期中性时信号数归零，依赖频繁交易的策略在中性期几乎不动作**——不写明使用者会认为模板失效。

## 2. 对齐规则（时间戳严格）

- **对齐必须严格按时间戳，不允许按 K 线序号对齐**（不同周期K线数量不对应）；
- **大周期K线收盘时间=小周期时间边界**（例：60min线10:30收盘=1min线10:30这根收盘时刻）；
- **小周期在边界之前的信号只能看到已完成的大周期K线，未完成的大周期K线不可见**。

## 3. A4 条件项：未完成大周期K线不可访问

- 策略上下文**只暴露已完成的大周期K线**；
- **取未完成的大周期K线直接抛异常**（与 S03 物理截断、S05 上下文只读同一机制）；
- 实现：**周期视图对象**——按最小周期推进，每次推进做大周期边界判定，命中边界则把已完成的大周期K线加入可见集，可见集按时间排序。

## 4. A7 条件项：三时点对齐用例

### TC-MC-001 边界前
- **场景**：小周期在 10:29（60min线10:30边界之前）产生信号。
- **断言**：上下文**不含10:30未完成的大周期K线**；只能看到10:30之前已完成的大周期K线；取未完成K线抛异常。

### TC-MC-002 边界时
- **场景**：小周期在 10:30（边界时刻）产生信号。
- **断言**：10:30大周期K线**已完成**，可进入可见集；信号可基于该K线决策。

### TC-MC-003 边界后
- **场景**：小周期在 10:31（边界之后）产生信号。
- **断言**：10:30大周期K线已入可见集；10:31之后的大周期K线未完成不可见。

### TC-MC-004 大周期方向融合
- **场景**：日线多头 + 60min线买入信号 → 通过；日线空头 + 60min买入信号 → **拒绝**（方向不允许）；日线中性 + 任何小周期信号 → **全部忽略**。
- **断言**：融合规则严格按方向三分执行；小周期无法单独开仓。

### TC-MC-005 盘中切换钉死
- **场景**：同一天内大周期方向在盘中被试图切换。
- **断言**：**日线收盘才切换，盘中不变**；无同一天内建仓又清仓的抖动。

### TC-MC-006 预热摊薄
- **场景**：60min线回测一年 vs 五年。
- **断言**：一年区间预热200根占两成时间，**成交笔数比五年少三成**——验证"短区间回测更差是预热摊薄非策略问题"。

## 5. 用例执行规范
- TC-MC-001~006 进回归；**TC-MC-001/002/003 为 A7 三时点核心用例**；
- 对齐检测在每次信号生成时自动执行（未完成大周期K线访问即抛异常，不依赖人工）；
- 融合规则与 S07 风控联动（方向不允许的委托在风控层再拦一道）。
