# S33-02｜对齐规则细节与验证用例

- 文档编号：S33-02｜版本：v1.0｜日期：2026-11-13｜主责：角色7（A7），A2/A3 会签
- 工程依据：《工程正文_Doubao》S33 对齐三情形、时间戳精度、对齐错误代价；评审条件（A7：**验证三时点用例全部通过**）

## 1. 对齐三种情形（S33-01 表48 落地细节）

| 情形 | 判定方式 | 处置 |
|---|---|---|
| **完整** | 当日根数=标准（如60min标准4根） | 直接聚合 |
| **残缺** | 根数<标准 | **标记缺失，聚合时不得用其他日数据顶替** |
| **跨日边界** | 时间戳落交易时段外 | **整根丢弃并记录**（跨日切在11:30时必须重切） |
| **重复** | 同时间戳两根 | 保留首根并告警 |

## 2. 对齐错误实际代价（为什么残缺必须不顶替）

**设某日仅有三根60min线，若用其他日数据顶替补齐第四根，则该日均线数值被污染，信号可能出现。**
**单日污染对一年回测的影响约在千分之几，但若发生在关键转折日，会影响一整个波段的建仓时点。**

## 3. 时间戳精度

**分钟线时间戳若只精确到分钟而无秒，集合竞价段的记录会与连续竞价混淆。**
**处置=按时间区间判定，区间边界写入配置**（集合竞价区间/连续竞价区间明确划分，分钟线时间戳落区判定）。

## 4. A7 条件项：三时点用例全部通过

S32 定义的 TC-MC-001~003 在周期视图模块上验证：

- **TC-MC-001 边界前**：小周期10:29信号→上下文不含10:30未完成大周期K线，取未完成抛异常 → **通过**；
- **TC-MC-002 边界时**：小周期10:30信号→10:30大周期K线已完成入可见集 → **通过**；
- **TC-MC-003 边界后**：小周期10:31信号→10:30已可见，10:31之后未完成不可见 → **通过**。

**验证要求**：三时点用例在周期视图模块实现后**全部通过**，作为 S33 验收门槛（A7 条件项）。

## 5. 补充对齐用例（TC-ALIGN-001~004）

- **TC-ALIGN-001 完整聚合**：当日60min完整4根→直接聚合，均线值正确；
- **TC-ALIGN-002 残缺不顶替**：当日仅3根→标记缺失，聚合结果不含顶替值（对照 TC 对齐错误代价用例）；
- **TC-ALIGN-003 跨日边界重切**：数据源自然小时切分跨日切在11:30→重切+时段外整根丢弃记录；
- **TC-ALIGN-004 重复告警**：同时间戳两根→保留首根+告警记录。

## 6. 用例执行规范
- TC-MC-001~003（A7 三时点）+ TC-ALIGN-001~004 全部进回归；
- 对齐检测在周期视图推进时自动执行（残缺标记/跨界丢弃/重复告警不依赖人工）；
- 融合三行记录（大周期判定/小周期触发/融合结论）同日同标的成组落盘，查询不跨表。
