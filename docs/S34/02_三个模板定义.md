# S34-02｜三个跨周期模板定义

- 文档编号：S34-02｜版本：v1.0｜日期：2026-11-13｜主责：角色4（A4），A3 会签
- 工程依据：《工程正文_Doubao》S34 三模板；**每个模板三要素：参数默认/敏感区间/失效行情**；A3 条件（最小周期一致）

---

## 模板一：日线定方向 + 60min择时（单边门控）

**信号规则**：
- **大周期（日线）**：双均线定多空——快线在上=多头、在下=空头、缠绕=中性；
- **小周期（60min）**：布林带回归择入场——跌破下轨买入、回到中轨清仓（仅在多头方向允许买入，空头方向允许卖出，中性全忽略，S32/S33 融合规则）；
- **盘中不切换**：日线收盘才切换方向（S32 钉死）。

**三要素**：
| 要素 | 内容 |
|---|---|
| **参数默认** | 日线快均线5/慢均线20；60min布林窗口20/倍数2 |
| **参数敏感区间** | 快均线2~60；慢均线10~120；布林窗口5~60、倍数1~3 |
| **失效行情** | **震荡市双均线频繁缠绕→方向频繁切换→信号抖动**；**单边急涨急跌中60min择时滞后→入场点位偏离** |

## 模板二：日线趋势 + 日线回调买点（触发型门控）

**信号规则**：
- **同周期（日线）分层**：**长均线定趋势**（如60日线方向）、**短均线定回调**（如10日线回踩长均线时买入）；
- 趋势向上且回调到位→买入；趋势向下→只卖不买（方向门控）；
- 本质是"大周期定方向、小周期（同周期短窗口）定时点"的触发型实现。

**三要素**：
| 要素 | 内容 |
|---|---|
| **参数默认** | 长均线60日、短均线10日 |
| **参数敏感区间** | 长均线20~120、短均线5~30 |
| **失效行情** | **趋势反转初期长均线滞后→回调买点落在下跌途中**；**长期横盘无趋势→回调买点频繁触发但无方向收益** |

## 模板三：周线过滤 + 日线跟随（共振型门控，最保守）

**信号规则**：
- **大周期（周线）**：过滤逆势段——周线趋势方向决定可做方向；
- **小周期（日线）**：跟随执行——日线信号须与周线方向共振才建仓；
- **双周期共振**：日线与周线方向一致才建仓，**交易次数最少**。

**三要素**：
| 要素 | 内容 |
|---|---|
| **参数默认** | 周线均线20周；日线入场用双均线5/20 |
| **参数敏感区间** | 周线均线10~40周；日线快均线2~60 |
| **失效行情** | **周线趋势与日线信号长期背离→几乎不交易（"少交易不等于差结果"的演示场景）**；**周线刚转向时日线共振滞后→错过启动段** |

## 公共约束（三模板共用）

1. **预热按最大周期的最大窗口计算**（模板三预热=周线20周+日线20日的最大窗口）；
2. **调仓只在日线收盘后决策**；
3. **60min信号只影响当根所属交易日的次日成交**（防盘中成交隐性前视，S34-01 §4）。

## A3 条件项：最小周期一致

**三个模板的最小周期一致**（均含日线作为最小决策周期，模板一/三的60min、周线为辅助周期），**便于横向对比**——模板间差异只来自融合逻辑（单边/触发/共振），周期选择统一。
