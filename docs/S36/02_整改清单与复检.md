# S36-02｜整改清单与复检细则

- 工程依据：《工程正文_Doubao》S36 表51、整改闭环、冻结期、复检两次；A4 条件（**统一拦截点集中在一处**）

## 1. 整改清单详表（每条附闭环三样）

### R-01｜盘中成交隐性前视（高危，72小时）
- **问题**：60min信号盘中即成交，违反"次日开盘成交"约定（S34 公共约束三），隐性前视。
- **复现步骤**：构造60min信号→检查成交时间戳是否在信号bar当日。
- **修复说明**：60min信号只影响当根所属交易日的次日成交；成交时间戳断言。
- **新增回归用例**：TC-FIX-001——盘中信号不成交、次日开盘成交。

### R-02｜分钟线跨界切分（高危，72小时）
- **问题**：数据源按自然小时切分，跨日切在11:30，分钟线归属错误。
- **复现步骤**：构造跨日切分数据→检查分钟线归属交易日。
- **修复说明**：跨日边界必须重切；时段外分钟线整根丢弃并记录（S33 表48 跨界）。
- **新增回归用例**：TC-FIX-002——跨界重切校验+时段外丢弃。

### R-03｜双周期预热不足（中危，两周）
- **问题**：双周期预热窗口未取各周期最大值，前段信号缺失。
- **复现步骤**：构造短区间回测→检查预热窗口覆盖。
- **修复说明**：预热按最大周期的最大窗口计算（S34 公共约束一）。
- **新增回归用例**：TC-FIX-003——预热断言（各周期最大窗口）。

### R-04｜回放状态不同步（中危，两周）
- **问题**：回放状态与账户状态不同步，三处自洽检测失效。
- **复现步骤**：回放中比对权益曲线/状态序列/成交明细。
- **修复说明**：回放状态一致性检测强制执行（S23 三处自洽）。
- **新增回归用例**：TC-FIX-004——回放一致性用例。

### R-05｜面板跳转顿卡（低危，下个版本）
- **问题**：回放面板跳转时界面顿卡。
- **复现步骤**：回放面板连续跳转。
- **修复说明**：跳转预加载+性能记录。
- **新增回归用例**：TC-FIX-005——跳转性能记录（不阻塞功能，下版本优化）。

## 2. A4 条件项：统一拦截点集中

**未完成大周期K线访问的统一拦截点集中在一处**：
- **所有读取入口共用一个拦截层**（周期视图的可见集访问），不在每个策略内自查；
- **策略主动请求未来边界→拦截层统一拒绝+记录违规**（对抗性测试口径）。

## 3. 整改后复检（高危两次）

**每条高危整改须复检两次：修复当次复检、下个版本前复检。**
**两次的原因=高危问题容易在后续重构中复活。**

## 4. 冻结期执行与回归重跑

- **冻结期两周内只允许修bug**：实际提交量从日均10次降到日均2次；
- **副作用警示**：提交量下降→测试发现的新问题变少，**容易误以为"质量提升了"，实际只是改动变少了**；
- **冻结期结束后必须重跑全部回归**（不能以冻结期低问题率作为质量结论）。

## 5. 用例执行规范
- TC-FIX-001~005 进回归；**高危两条（R-01/R-02）附两次复检**；
- 每条整改三样（复现/修复/用例）齐全才算闭环，缺一即未闭环。
