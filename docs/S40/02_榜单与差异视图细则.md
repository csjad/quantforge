# S40-02｜榜单与差异视图细则

- 文档编号：S40-02｜版本：v1.0｜日期：2026-11-13｜主责：角色6（A6），A3 会签
- 工程依据：《工程正文_Doubao》S40 列设计、排名呈现、成本拆分；A3 条件（**成本结构按佣金、印花税、滑点三项拆分**）

---

## 1. 榜单视图细则

### 1.1 十列结构
| 列 | 说明 |
|---|---|
| 策略名 / 版本 | 标识 |
| 三维度分项 | 风险调整/稳健性/成本效率三项 |
| 加权总分 | 三维加权结果（权重打印在榜单头部，S38） |
| 交易次数 | 笔数（笔数不足叠加警示色，S38） |
| 最大回撤 | 峰值口径（S09） |
| 换手率 | 双边口径（S09） |
| 状态 | 完成/未完成（S39 未完成区块） |

### 1.2 排序与切换记录
- **默认按加权总分排序**；
- **切换排序键（如按夏普/按回撤）时记录切换行为**——切换历史可查，防止排名基准被切换后遗忘。

## 2. 对比表12列（固定顺序）

**策略、参数摘要、累计收益、年化、波动、夏普、最大回撤、卡玛、胜率、盈亏比、笔数、完成状态。**
**十二列固定顺序，不允许自定义**——**固定顺序让不同截图之间可比**。

## 3. 差异视图三处重点

| 处 | 内容 | 用途 |
|---|---|---|
| **指标差异** | 十二项指标逐项差值 | 总体差异 |
| **分年度差异** | 各年度表现差异 | 差异稳定性（S38 判据） |
| **成本结构差异** | **按佣金、印花税、滑点三项拆分** | **解释"为什么A看起来更好但净收益更低"** |

**A3 条件项**：**成本结构三项拆分**——佣金/印花税/滑点各自差值，让使用者看到收益差被哪项成本吃掉，而非一个笼统的"成本差异"。

## 4. 排名只做两项并列（不给综合排名）

**按夏普排序 + 按最大回撤排序，两项并列展示。**
**不给综合排名的理由**：**两项常互相矛盾，矛盾本身有信息量——高夏普低回撤的策略极罕见，多数策略在两者间取舍，让使用者看到取舍比给一个名次更有用**。

## 5. 导出限制

- **表格形态**：榜单/差异数据；
- **报告形态**：**必须含"本擂台不可用于跨擂台比较"的声明**——**数据快照不同则结论不可比**（与 S38 四项公平锁同源）。

## 6. 用例要点（S41 回归落点）
- **TC-PANEL-001 十列固定**：榜单列固定+不可自定义；
- **TC-PANEL-002 排序切换记录**：切换排序键→记录切换行为；
- **TC-PANEL-003 差异三处**：任选两策略→指标/分年度/成本结构三处齐全；
- **TC-PANEL-004 成本三项拆分**（A3）：成本差异按佣金/印花税/滑点拆分，非笼统成本；
- **TC-PANEL-005 排名两项并列**：只出夏普+回撤两项，无综合排名；
- **TC-PANEL-006 导出声明**：报告导出含"不可跨擂台比较"声明。
