# S41-02｜公平性断言、浮点比较与复跑细则

- 文档编号：S41-02｜版本：v1.0｜日期：2026-11-13｜主责：角色7（A7），A3 会签
- 工程依据：《工程正文_Doubao》S41 表56、隐性随机、复跑阈值；A3 条件（**浮点比较使用相对误差阈值**）

## 1. 五断言逐条说明

| 断言 | 检查内容 | 失败处置 |
|---|---|---|
| **快照一致** | 擂台内所有任务数据快照号相同 | 拒绝启动 |
| **费率一致** | 全组费率滑点配置逐字段相等 | 拒绝启动 |
| **区间一致** | 起止日与标的池完全一致 | 拒绝启动 |
| **脚本一致** | 十二项指标由同一评估脚本计算 | 拒绝启动 |
| **种子显式** | 含随机种子的策略必须显式设种子 | 拒绝启动 |

## 2. 浮点比较（A3 条件项）

**浮点比较使用相对误差阈值。**
- **绝对误差在浮点场景不可靠**（大数小数的绝对差相同但相对意义不同）；
- **相对误差阈值=千分之五**（与复跑一致性阈值一致）；
- **实测正常浮点差异在千分之一以内，千分之五给四倍余量**，超过即判定存在随机源而非浮点噪声。

## 3. 隐性随机的三种来源与定位

| 来源 | 表现 | 定位手段 |
|---|---|---|
| **策略内部随机采样未设种子** | 两次运行结果不同 | 种子显式断言（表56 第五条） |
| **遍历器打乱任务顺序→浮点求和顺序不同** | 复跑偏差超千分之五 | 固定遍历顺序+复跑比对 |
| **缓存命中与否影响指标预热** | "有缓存vs无缓存"两次运行偏差 | **复跑一致性验证（最隐蔽，使用者通常只跑一次）** |

**复跑是发现隐性随机的唯一实用手段**——三种来源都会让复跑偏差超过千分之五，复跑比对把隐性随机逼到台面上。

## 4. 复跑验证流程

1. **抽前两名策略**各复跑一次；
2. **比对十二项指标**；
3. **偏差<千分之五（相对误差）视为一致**；
4. **不一致→定位未声明随机源→消除→重跑复验**；
5. **复跑通过才允许榜单生效**。

## 5. 用例要点（S42/S43 回归落点）
- **TC-FAIR-001 四项校验**：修改快照/标的池/费率/基准任一项→拒绝生成榜单；
- **TC-FAIR-002 五断言前置**：提交时校验，不边跑边校；
- **TC-FAIR-003 种子显式**：未设种子策略→拒绝启动；
- **TC-FAIR-004 一致性测试**：同一策略提交两次→结果完全一致；
- **TC-FAIR-005 复跑验证**：前两名复跑→十二项偏差<千分之五（相对误差，A3）；
- **TC-FAIR-006 隐性随机定位**：构造三种隐性随机源→复跑发现并消除。
