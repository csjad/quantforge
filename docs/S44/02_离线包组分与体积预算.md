# S44-02｜离线包组分明细与体积预算

- 文档编号：S44-02｜版本：v1.0｜日期：2026-11-13｜主责：角色8（A8），A2/A7 会签
- 工程依据：《工程正文_Doubao》S44 体积构成、样例数据独立成包、三次验证；A2 条件（**样例数据附来源与授权说明**）

---

## 1. 包体积实际构成（主包200MB上限）

| 项 | 体积 |
|---|---|
| 运行时（解释器+依赖） | 约85MB |
| 依赖 | 约40MB |
| **样例数据** | **约50MB** |
| 文档 | 约10MB |
| 脚本与模板 | 不足1MB |
| **合计** | **约186MB（在主包200MB上限内）** |

## 2. 样例数据独立成包（关键决策）

**样例数据50MB对应五个标的五年日线，加一个池的元信息。**
**若加到50标的，体积升到120MB，主包会超限——因此样例数据必须独立成包。**

**合规口径**：**样例数据须为自制或公开授权，不得使用来源不明的数据**（商品化合规底线）。
**A2 条件项**：**样例数据附来源与授权说明**——随数据包分发授权声明。

## 3. 三次验证的失败率（裁剪后实测）

| 验证环境 | 失败率 |
|---|---|
| **本机新目录解压运行** | 约两成 |
| **干净虚拟机运行** | 约一成 |
| **无网络机器运行** | 约半成 |

**两次失败均为字体缺失导致图表乱码**——**处置为把字体随包分发**（与 S11 PDF 字体内嵌、S18 命令实测同源，字体是交付最常见的坑）。

## 4. 体积控制的三条手段（S45 承接）

1. **依赖白名单**：只装实际引用的库，逐条核对导入语句；
2. **二进制裁剪**：去掉测试、文档、未使用编译产物；
3. **数据与程序分离打包**：程序包约百余兆，数据包按需分发。

**三条目标=主包控制在200MB以内**——**超过200MB，常见传输方式（网盘/邮件附件/U盘拷贝）都会变得费劲，而费劲会直接影响交付体验。**

## 5. 用例要点（S46 回归落点）
- **TC-OFFLINE-001 五件事离线**：断网环境完成启动/导入/回测/报告/查看五件事；
- **TC-OFFLINE-002 30分钟目标**：断网新机器30分钟内出首份报告；
- **TC-OFFLINE-003 样例数据合规**（A2）：样例数据附来源与授权说明，无来源不明数据；
- **TC-OFFLINE-004 在线拉取关闭**：离线包在线源默认关闭，启动检查提示"不含在线拉取"（C-039）；
- **TC-OFFLINE-005 体积预算**：主包≤200MB，样例数据独立成包；
- **TC-OFFLINE-006 字体随包**：图表不乱码（字体缺失曾致两次验证失败）。
