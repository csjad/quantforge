# S46-02｜断网验证用例与缺陷清单细则

- 文档编号：S46-02｜版本：v1.0｜日期：2026-11-13｜主责：角色7（A7），A8 会签
- 工程依据：《工程正文_Doubao》S46 四步验证/表61/失败归因；S45 离线包

---

## 1. 断网验证记录格式（A8 条件项：附每步耗时）

**验证记录必须附每步耗时**（A8 条件，工程原文"要求验证记录附每步耗时"），逐步骤登记：

| 字段 | 说明 |
|---|---|
| 步骤 | 准备断网/解压与启动/样例回测/复核报告 |
| 开始/结束时间 | 精确到分钟 |
| 耗时 | 实测值，对照表61基线与上限 |
| 通过判据 | 四步各自的判据结果 |
| 三处隐式依赖检查 | 隐式在线依赖/启动远程检查/报告在线资源，逐项结论 |
| 断网断言 | 外网请求断言失败的证据 |
| 缺陷归因 | 环境类/包类/数据类，逐条登记 |

## 2. 用例清单

| 编号 | 用例 | 通过标准 |
|---|---|---|
| **TC-VER-001** | 断网环境准备 | 物理断网或防火墙全阻断，**确认无代理可绕过** |
| **TC-VER-002** | 断网断言 | **执行一次外网请求并断言失败**；不断言不得判定断网成立 |
| **TC-VER-003** | 解压与启动 | 按说明解压启动成功，**记录每步耗时**，对照表61基线 |
| **TC-VER-004** | 隐式在线依赖检查 | 字体下载/时区数据/包索引**无隐式在线依赖** |
| **TC-VER-005** | 启动远程检查跳过 | 启动过程零联网，C-039 启动提示不发起远程请求 |
| **TC-VER-006** | 样例回测 | 内置样例数据+模板跑出报告，对照表61上限（十二分） |
| **TC-VER-007** | 报告复核 | **九项配置齐全、指标可读、图表正常** |
| **TC-VER-008** | 三处判据总判 | **三处隐式依赖检查任一失败即判定离线包不合格**；四步全过才算通过 |
| **TC-VER-009** | 耗时总控 | 合计≤25分钟（超限须优化启动流程**而非放宽目标**，对上30分钟目标） |
| **TC-VER-010** | 缺陷归因 | 失败按环境类/包类/数据类分别记录、分别处置 |

## 3. 缺陷清单登记规则（三类归因，处置完全不同）

| 类 | 登记要求 | 处置路径 |
|---|---|---|
| **环境类**（缺字体、缺运行库、端口占用、目录权限） | 记录现象+发生步骤+耗时影响 | **写进说明**（不改代码）——失败集中在启动占七成，多属此类 |
| **包类**（依赖缺失） | 记录缺失模块+触发步骤 | **回炉重打**（S45 重新打包） |
| **数据类**（样例数据未对齐） | 记录未对齐项+影响范围 | **重新生成样例**（S44 合规口径复核） |

**每条缺陷必须归入三类之一**；归因不清的缺陷按最接近类登记并标注"待复核"，**不允许无归因挂账**。

## 4. 验证执行纪律

1. **先断言断网，再跑四步**——步骤一失真则全部结论失真（只关浏览器不阻断出站=库悄悄联网成功）；
2. **每步留痕**——耗时、判据、证据三件套齐全；
3. **三处检查在四步中贯穿**——不单独拆时间，但在记录中逐项给结论；
4. **失败不放宽**——超25分钟优化启动流程，不放宽30分钟目标（工程原文口径）。
