## 2. 灾备用例清单（TC-DR-001~005）

| 编号 | 用例 | 破坏方式 | 通过判据（须可执行化） |
|---|---|---|---|
| **TC-DR-001** | 元信息恢复 | 删库 | **标的数与快照一致**（给出统计命令与期望值） |
| **TC-DR-002** | 分区恢复 | 删分区 | **行数与校验和一致**（给出统计命令与期望值，如"行数应为五千、校验和应为某十六位串"） |
| **TC-DR-003** | 配置恢复 | 清空 | 恢复默认配置后**服务可启动**，差异清单核对 |
| **TC-DR-004** | 密钥恢复 | 失效 | 重新注入后**鉴权通过** |
| **TC-DR-005** | 整机迁移 | 新机 | 新机器安装后恢复全部数据，**全流程可跑** |

**判据可执行化硬规则**：判据必须给出**具体命令与期望输出**；**只写"一致"不可验收**——第二个人无法执行就无法验收。

## 3. 演练执行与记录细则

- **演练环境**：离线环境（与 S46 断网口径一致）；
- **演练总判据**：**一小时内恢复且结果可比对**；
- **耗时基线**（工程正文实测）：元信息恢复1分钟/分区恢复20秒/配置恢复10秒/密钥恢复30秒/**整机迁移35分钟**，合计约38分钟——**整机迁移占九成，是"恢复一小时"目标的实际约束项**；
- **演练记录四要素**：目的、破坏步骤（含具体命令与路径）、恢复步骤（含具体命令与路径）、判据（含期望输出）；
- **禁止表述**："按常规方式恢复"等无具体命令的表述——**四段必须能被第二个人照做**。

## 4. 演练结论登记（灾备演练结论产出格式）

| 字段 | 说明 |
|---|---|
| 用例 | TC-DR-001~005 逐条 |
| 破坏方式 | 删库/删分区/清空/失效/新机 |
| 恢复耗时 | 实测值，对照基线 |
| 判据结果 | 期望输出与实际输出逐项核对 |
| 结论 | 通过/失败（失败须回炉并复练） |
| 总判据 | 一小时内恢复且结果可比对 |

**演练结论必须回答"最坏情况下能不能救回来"，而非"平常能不能跑"**——交付后遇数据损坏且无备份，用户损失不可逆。
