# S48-02｜常见离线故障清单（六类）

- 文档编号：S48-02｜版本：v1.0｜日期：2026-11-13｜主责：角色8（A8），A7 会签
- 工程依据：《工程正文_Doubao》S48 第二节六类故障（每类给出症状、原因、修复三步）；**A7 条件项：六类故障均可在离线环境复现**

## 1. 六类常见故障（已冻结）

**每类给出症状、原因、修复三步。**

### 故障一：端口占用
- **症状**：启动时报端口绑定失败，服务起不来；
- **原因**：8080 等端口被其他程序占用（本机实测：8080 被 Qwen38 占用，C-004 口径）；
- **修复**：①按启动自检提示找到占用进程；②停用占用程序或改用备用端口启动参数；③重启服务并复查自检五项全过。

### 故障二：磁盘不足
- **症状**：导入样例或跑回测中途报写盘失败；
- **原因**：数据目录所在盘剩余空间低于回测产物与日志所需（日志每日二百兆字节量级，附录C 口径）；
- **修复**：①清理数据目录中的旧报告与日志；②按"磁盘按总量两倍配置，留三成余量"（附录C）扩容或迁移目录；③重新执行导入。

### 故障三：镜像导入失败
- **症状**：离线运行时导入报错或直接缺文件；
- **原因**：传输损坏（网盘中断产生可解压但内容缺损的包，S45 口径）或解压路径含中文/空格；
- **修复**：①先比对校验和（S45 口径：校验和防传输损坏）；②校验和不一致→重新下载；③确认解压路径不含中文与空格后重试。

### 故障四：样例数据缺失
- **症状**：启动后无数据可回测，卡在第一步（S44 结论：五组分最常缺样例数据）；
- **原因**：使用者只拿到程序包，样例数据包未随包分发；
- **修复**：①核对五组分齐备检查清单（S44）；②从独立样例数据包重新导入；③导入后跑样例回测确认五件事链路通。

### 故障五：字体缺失导致报告乱码
- **症状**：报告图表中文乱码或方块字；
- **原因**：目标机器缺中文字体（S45 实测：两次验证失败均为此因，处置=字体随包分发）；
- **修复**：①确认包内 fonts 目录存在；②若被误删，从原始包重取字体文件放入指定目录；③重新生成报告核对图表正常（对接 TC-VER-007）。

### 故障六：时区不一致导致日期错位
- **症状**：K线日期与报告日期错位一天，或分钟线对不齐；
- **原因**：目标机器时区/系统时间与数据快照时区不一致；
- **修复**：①核对系统时区设置；②按数据快照标识核对时区口径（S03 九步时序的 timestamp 对齐原则）；③修正时区后重新导入受影响数据。

## 2. A7 条件项：六类故障均可在离线环境复现（已落实）

**六类故障的复现方法（离线环境可操作）**：

| 故障 | 离线复现方法 |
|---|---|
| 端口占用 | 用占位程序占用目标端口后启动 |
| 磁盘不足 | 限额填充数据目录所在盘至阈值下 |
| 镜像导入失败 | 截断包 400KB（S45 TC-PKG-007 口径）后解压导入 |
| 样例数据缺失 | 移除样例数据目录后启动 |
| 字体缺失 | 移除包内 fonts 目录后生成报告 |
| 时区不一致 | 将系统时区改为相差一天后导入比对 |

**复现通过标准**：症状与本章描述一致、修复三步执行后故障消除。
