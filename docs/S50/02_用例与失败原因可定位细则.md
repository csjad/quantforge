## 1. A7 条件项：校验失败原因可读且可定位（已落实）

**工程原文要求：校验失败原因可读且可定位。落实口径：**

- **每条被拒草案必须返回结构化失败记录**：步骤（五步之一）/拒绝类别（五类之一）/失败描述（人话）/定位信息（指标名、参数名、索引位置或沙箱违规项）；
- **"指标不存在"类失败必须附可用指标清单与相似名建议**（S49 日志形态冻结结论——多数错误是拼写或改名，给建议能让人一次改对）；
- **失败记录随草案一并入库**，可在草案详情页查看，不散落日志。

## 2. 用例清单

| 编号 | 用例 | 通过标准 |
|---|---|---|
| **TC-GEN-001** | 生成四步串联 | 取相似策略→抽共性→改写→出草案，四步顺序执行、草案只含规则文本与参数区间 |
| **TC-GEN-002** | 校验三步串联 | 静态扫描→沙箱运行→结果评估，任一失败即返回失败原因 |
| **TC-GEN-003** | 五步漏斗计数 | 草案生成/静态检查/沙箱试跑/小样本回测/转正五步逐级计数可输出 |
| **TC-GEN-004** | 静态检查三件事 | 指标存在/参数界内/无正偏移索引，三项逐项判定 |
| **TC-GEN-005** | 沙箱试跑三禁 | 不越权、不联网、不超时，违规即终止并标记不安全 |
| **TC-GEN-006** | 小样本回测 | 五十只标的跑一年，有成交且三守恒式通过 |
| **TC-GEN-007** | 失败原因可读可定位（A7） | 五类拒绝分别返回结构化记录；"指标不存在"附可用清单与相似名建议 |
| **TC-GEN-008** | 拒绝五类分别记数 | 指标不存在/参数越界/索引前视/沙箱违规/回测无成交五类分列统计，按批次汇总 |
| **TC-GEN-009** | 系统性偏差识别 | 参数越界占比超一半时给出"修生成器"提示，而非逐条修草案 |
| **TC-GEN-010** | 转正门槛 | 五步全过+成交笔数≥5笔转正入库；不足标"观察中"；通过率口径（约三成/两成/一成）随批次输出 |

## 3. 拒绝记录格式（结构化，验收口径）

| 字段 | 说明 | 示例 |
|---|---|---|
| draft_id | 草案编号 | D-20261113-017 |
| step | 五步之一 | 静态检查 |
| reject_class | 五类之一 | 指标不存在 |
| message | 人话描述 | 引用了不存在的指标名 "MACD_FAST" |
| locator | 定位信息 | 第 12 行；可用指标清单见附页；相似名建议："MACDfast" |
| disposition | 处置 | 退回草案（表65） |

## 4. 批次汇总报表口径

- 每批次输出：总数/五类拒绝分列计数/四级漏斗（静态/沙箱/回测/转正）通过数/总耗时；
- **对照基线**：约三成过静态、两成过沙箱、一成过回测（S50-01 §7）；单条平均耗时约四十七秒（S50-01 §8），批次耗时=单条×数量（一百条约八十分钟）；
- **偏差告警**：任一类拒绝占比超一半→批次报表标注"生成器系统性偏差，建议修生成器"。
