## 3. 冲突 C-041｜V9~V12 路线主题不一致（工程正文S51内部冲突，顺延登记）

- 发现阶段：工程正文S51内部（技术正文 vs 深度展开/表66/表67）→ 项目S51（工程正文内部未编号冲突；项目顺延登记为C-041）
- 冲突原文甲（技术正文）：V9多租户隔离（解决多人共用）、V10审计日志不可篡改（解决合规追溯）、V11移动只读面板（解决查看便利）、V12单点登录与组织权限（解决企业接入）
- 冲突原文乙（深度展开+表66+表67）：V9多用户隔离、V10跨市场扩展、V11策略市场（条目共享与评价）、V12自动化研究流水线
- 量化差值：V9~V12 四版主题完全不同
- 风险等级：高（路线图是长期迭代纲领，主题不一致将导致后续版本规划分裂）
- 失效后果：按不同路线开工会做完全不同的产品
- 方案1：**以深度展开+表66+表67为准（乙）**——乙有完整依赖推导（四条依赖各有具体技术原因）、表66前置依赖与风险、表67触发条件与不达条件处置，内部自洽；且与产品定位一致（私有化单机部署、个人散户/量化爱好者/学生客群，D-001/S00 口径）
- 方案2：以技术正文为准（甲）——甲的企业化主题（审计不可篡改/SSO组织权限）与 D-001 定位不符，且无依赖推导与触发条件
- 方案对比：方案1自洽且贴合定位，甲中兼容项保留映射；方案2需推翻表66/67全部推导
- **选定方案：方案1**
- 甲乙兼容项映射：V8 多机回测集群≈分布式跑批（两口径一致）；甲技术前提"V9数据层加租户字段"与乙兼容保留；甲风险台账中 V8任务重复执行、V9水平越权与乙兼容保留，V10存储成本膨胀在跨市场（数据量增大）语境下仍成立，V11权限边界模糊改写为内容质量风险、V12集成复杂度改写为幻觉风险（按乙主题）
- 需回溯修改的清单：本阶段路线图统一按乙主题；风险台账按映射改写
- 修改完成确认标记：已完成

## 4. 五版路线图（选定乙口径，已冻结）

| 版本 | 主题 | 解决的问题 |
|---|---|---|
| **V8** | **分布式跑批（多机回测集群）** | 单机算力上限 |
| **V9** | **多用户隔离** | 多人共用 |
| **V10** | **跨市场扩展** | 港股/美股数据结构差异 |
| **V11** | **策略市场（条目共享与评价）** | 策略条目流通 |
| **V12** | **自动化研究流水线** | 研究自动化 |

**五版技术前提**：V8 任务队列可跨机消费；V9 数据层加租户字段；V10 分区策略已抽象（V8 后）加市场只需加映射；V11 依赖 V7 知识库条目池成熟；V12 依赖 V8 算力与 V11 条目池。

## 5. 跨版本兼容策略三条（已冻结）

1. **数据表新增字段一律可空并给默认值**，避免旧数据不可读；
2. **接口只增不改，废弃接口保留两个版本**；
3. **策略接口永不变更，变更只发生在引擎内部。**

## 6. 风险台账五条（按乙主题映射，已冻结）

| 版本 | 主要风险 | 等级 |
|---|---|---|
| V8 | **任务重复执行**（分布式跑批改动面大） | 中 |
| V9 | **水平越权**（多用户隔离安全） | 高 |
| V10 | **数据层重构/存储成本膨胀**（跨市场数据量与结构差异） | 中 |
| V11 | **内容质量**（策略共享的条目质量） | 高 |
| V12 | **幻觉**（自动化研究生成误导性结论） | 高 |
