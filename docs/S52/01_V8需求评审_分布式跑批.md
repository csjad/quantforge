## 2. 触发条件复测（H-S51-01 落实，铁律一数值优先）

**复测结论：触发条件未自然达成。**

| 口径 | 实测 |
|---|---|
| 全池（5标的×5年）单组 | **25ms**（10 组实测 0.25s） |
| 全池双参数单组 | **31ms**（20 组实测 0.62s） |
| **1000 组外推（单机串行）** | **25~31 秒 ≈ 0.5 分钟** |

蓝图"千组=单机 11 小时"的假设对应 **500 标的×多年真实数据**的重负载（S06-01 表17：池内500标的单组≈15分钟）。W1 规模下该前提不成立。

**处置（本阶段核心决策）**：按用户指令启动 V8 评审（显式指令=最高优先级）；V8 能力按蓝图定位做成 **"默认关的可插拔分布式后端"+触发器参数化**——触发器=配置项（遍历组数阈值/标的池规模/单组耗时基线三取一），达标自动启用分布式，不达标保持单机串行。**这同时满足"不达条件保持单机"（冻结口径）与"V8 能力建成"（用户指令）**。新增假设 H-S52-01 见《S52-03》。

## 4. 明确不做（不为 V8 塞功能，S51 定位写死）

**不加新策略功能、不动策略接口（S51 兼容第三条）、不做多用户（V9 前置 V8 依赖链不变）、不动引擎语义（三守恒/九步时序原样）。**
V8 只做一件事：**让同一批遍历任务可以在"单机串行 / 本机并行 / 远程算力"三种后端之间切换，且结果逐位可比。**

## 5. 验收口径（预置）

- **结果可比性**：同一任务在单机串行与本机并行两种后端下，**每组参数的结果逐位一致**（浮点口径同 S04 容差）——并行化只改执行位置，不改计算语义；
- **幂等**：同一 task_id 重复提交/进程中断重启 → 已完成组不重算、不重复落盘；
- **回归**：触发器未达 → 走原单机串行路径，现有 90 测试全绿不动；
- 性能：1000 组在并行后端下 ≤ 单机串行耗时 × 0.6（核数−4 折算下限）。
