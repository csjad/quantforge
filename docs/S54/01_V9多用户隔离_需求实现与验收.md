| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| **V9-01** | 用户作用域路径隔离（data/users/<u>/ 与 out/users/<u>/） | 必须 | CLI `--user`（只增参数） |

数据层"租户字段"（S51 技术前提）为部署形态 PG 口径——分文件隔离更彻底且零 schema 变更。

## 2. 实现（src/qf/users.py + CLI --user）

- `user_scope(root, user)`：解析 data/out/db 三路径；`user=None` → 历史默认路径；
- **越权防线**：`USER_NAME_RE = ^[\w\-]{1,32}$`（拒绝路径分隔符/`..`/超长）；
  `assert_containment`（resolve 后必须在作用域之下）；kline/results 目录派生同样过断言；
- CLI：backtest/sweep/show 新增 `--user`（只增）。

## 3. 教程短章（按 S19 附录A.10 四段模板）

- **本节目标**：让第二个人在同一台机器上用互不污染的账户跑回测；
- **操作步骤**：`python qf.py backtest --user alice --strategy ma_cross`（结果落
  `out/users/alice/`，任务库 `data/users/alice/qf.db`）；查看：`--user alice`；
- **常见报错**：`非法用户名`（用了中文/斜杠/超长）→ 换字母数字；`路径越权` →
  不要手工挪动 data/users 结构；
- **完成标志与自测**：两个 `--user` 各跑一次 demo，互看不到对方 run_id（`show` 验证）。
