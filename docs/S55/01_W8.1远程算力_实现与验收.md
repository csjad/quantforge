## 1. 协议三环节（真实 HTTP，127.0.0.1 动态端口）

| 环节 | 实现 |
|---|---|
| **分片认领** | `GET /claim?token=..&worker=..` → 弹出下一任务（幂等 task_id） |
| **结果回传** | `POST /result?token=..` → 结果 JSON 落盘（`sweep_results/{task_id}.json`）+ bt_tasks 双确认置已完成 |
| **鉴权（V8-06 落地）** | token 不匹配 → **403 + 拒绝记录**（master.denied 留痕）——S51 A5 条件"V9 越权测试提前准备"的另一半兑现 |

**启用条件（冻结）**：仅显式选择（`--backend remote`）；**auto 永不产生 remote**（decide_backend 白名单放行显式 remote，本阶段修复的正是这一越权覆盖缺陷——auto 曾把显式 remote 误降级为 serial）。

## 2. 实现与真实验收

- **E2E 闭环**：主控线程（ThreadingHTTPServer）+ worker 子进程真实 HTTP 认领/回传——
  2 组任务 → 结果落盘 + bt_tasks 已完成两行 + `sweep_results/` 两文件（TC-REMOTE-002）；
- **三后端逐位一致**：serial / parallel / remote 同 seed → records **逐位相等**
  （TC-REMOTE-003）——三后端共用 `_rank_key` 与同版本 run_combo；
- **诚实边界**：worker 与主控同机共享数据文件（跨机数据同步=部署形态）；
  单组 300s 超时以整批 deadline+**无进展护栏**（快照 30 秒无变化即放弃，防 worker
  早死导致无限等待——实现期真 bug，见 §3）执行。

## 3. 实现期真 bug 三连（诚实记录，全部由测试逼出）

1. **bt_tasks 无行**：远程路径只 UPDATE 不 INSERT——master 启动时预插任务行（待执行）；
2. **sqlite 跨线程 ProgrammingError**：/result 回调在 HTTP 线程写库 → `check_same_thread=False`+写路径 master.lock 串行化（parallel.open_tasks 注释登记）；
3. **auto 覆盖显式 remote**：decide_backend 白名单漏 remote → 显式选择被误降级 serial——修复并补"auto 永不产生 remote"的断言语义。

## 5. 教程短章（四段模板）

- **目标**：第二台机器（或第二个终端）分担遍历算力；
- **步骤**：主控 `python qf.py sweep ... --backend remote`（自动起服务）+ worker `python src/qf/remote_worker.py --master http://127.0.0.1:<port> --token <token> --bars <csv>`；
- **常见报错**：403=token 不一致；无结果=数据文件路径不通（同机共享口径）；
- **完成标志**：`bt_tasks` 全部"已完成"且 `sweep_results/` 文件数=组数。
